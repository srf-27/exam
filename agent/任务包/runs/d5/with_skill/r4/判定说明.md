# 检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- 数据：《巡检数据.csv》（本次共 9 台设备）
- 结论值域：需检修 / 无需检修 / 不适用
- 判定顺序：先看 4.3（排除），再按 4.1（含空值回退）与 4.2，命中任一即「需检修」。

## 判定规则摘要

1. **4.1 温度**：运行温度**严格大于**额定温度上限 → 需检修。
   - 回退规则：**额定温度上限列为空时，按机柜级限值执行**——通用计算机柜 **62 ℃**，高密度 GPU 机柜 **80 ℃**。
   - 「超过」按严格大于处理，等于上限不算超限。
2. **4.2 告警**：24 小时内告警 **≥3 次** → 无论温度是否超限，均判需检修。
3. **4.3 排除**：状态为「厂商保修返修中」的设备**不纳入本次判定**，判为「不适用」；该条优先于 4.1、4.2。

## 逐台理由

**SV-501　需检修（4.2）**
额定上限为空，按其机柜级限值执行：A-01 为通用计算机柜，限值 62 ℃。运行温度 60 ℃，60 ≤ 62，未超限，4.1 不触发。但 24h 告警 3 次，≥3，触发 4.2，判需检修。
（要点：温度虽正常，仍因告警次数达标而检修。）

**SV-502　无需检修（无）**
额定上限为空，按通用计算机柜限值 62 ℃，运行温度 60 ℃未超限；24h 告警 0 次 <3 次。4.1、4.2 均不触发，判无需检修。

**SV-503　需检修（4.1、4.2）**
额定上限 70 ℃，运行温度 75 ℃ > 70 ℃，超限，触发 4.1；24h 告警 3 次 ≥3，同时触发 4.2。两条均命中，判需检修。

**SV-504　需检修（4.1）**
额定上限 70 ℃，运行温度 75 ℃ > 70 ℃，超限，触发 4.1；24h 告警 2 次 <3 次，不触发 4.2。仅凭温度超限即判需检修。

**SV-505　无需检修（无）**
额定上限 88 ℃，运行温度 85 ℃ ≤ 88 ℃，未超限；24h 告警 0 次 <3 次。4.1、4.2 均不触发，判无需检修。

**SV-506　不适用（4.3）**
状态为「厂商保修返修中」。按 4.3 该设备不纳入本次判定，直接判「不适用」。虽然运行温度 95 ℃ > 额定上限 88 ℃、单独看会触发 4.1，但排除条款 4.3 优先，故不判需检修。
（要点：数值超标却判不适用，体现 4.3 的排除优先。）

**SV-507　需检修（4.1、4.2）**
额定上限为空，按其机柜级限值执行：B-02 为高密度 GPU 机柜，限值 80 ℃。运行温度 81 ℃ > 80 ℃，超限，触发 4.1；24h 告警 5 次 ≥3，同时触发 4.2。两条均命中，判需检修。

**SV-508　无需检修（无）**
额定上限 66 ℃，运行温度 66 ℃。规范表述为「超过」，按严格大于处理，66 等于 66 不算超过，4.1 不触发；24h 告警 0 次 <3 次。判无需检修。

**SV-509　需检修（4.1）**
额定上限 66 ℃，运行温度 67 ℃ > 66 ℃，超限，触发 4.1；24h 告警 0 次 <3 次，不触发 4.2。判需检修。

## 备注

- 工作区内未提供示例（样例判定/已填样表），故未做「用示例校准判定顺序」这一步；判定顺序依规范措辞确定：4.3 为「不纳入本次判定」的排除规则，优先于 4.1、4.2。
- 本次涉及空值回退的设备为 SV-501、SV-502、SV-507，均已按机柜用途取 62 ℃ 或 80 ℃ 限值。
- 输入文件《巡检数据.csv》《设备维护规范.md》保持只读未改动。
