# 机房设备停机检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 章
- 数据来源：`巡检数据.csv`（本次巡检 9 台，SV-501 ~ SV-509）
- 判定值域：需检修 / 无需检修 / 不适用
- 判定结果见：`检修判定表.csv`

## 一、判定规则与优先顺序

规范里的硬约束共 4 条（4.1 含一条缺省规则），实际执行顺序如下：

1. **4.3 排除（最高优先）**：状态为「厂商保修返修中」的设备不纳入本次判定，直接判「不适用」。该设备即使温度超限或告警超标，也不再按 4.1/4.2 判定。
2. **4.1 温度超限**：运行温度严格**大于**额定温度上限的，判「需检修」。等于不算超过。
   - **缺省规则**：巡检数据中「额定温度上限」列为空的设备，改按其**机柜级限值**执行——由「机柜用途」列决定：通用计算机柜 **62 ℃**，高密度 GPU 机柜 **80 ℃**。
   - 注意：机柜级限值只在该列为空时兜底；该列有值时一律以行内数值为准，机柜限值不参与比较。
3. **4.2 告警次数**：24 小时内告警 **≥3 次**的，**无论温度是否超限**，均判「需检修」。
4. 以上均未触发 → 判「无需检修」。

顺序说明：4.3 是排除条款，优先于 4.1/4.2；4.1 与 4.2 可能同时命中，命中时两条并列为触发条款（结论同为「需检修」，无冲突）。

## 二、逐台说明

### SV-501 —— 需检修（触发 4.2）
- 该行「额定温度上限」为空，按缺省规则取**通用计算机柜限值 62 ℃**。
- 运行温度 60 ℃，未超过 62 ℃，4.1 不触发。
- 24h 告警 3 次，**≥3 次**，触发 4.2，且 4.2 明确「无论温度是否超限」。
- 结论：温度虽正常，但告警达标，判**需检修**。

### SV-502 —— 无需检修（无触发条款）
- 额定温度上限为空，按通用计算机柜限值 62 ℃；运行温度 60 ℃ 未超过 62 ℃。
- 24h 告警 0 次 < 3 次。
- 结论：4.1、4.2 均未触发，判**无需检修**。

### SV-503 —— 需检修（同时触发 4.1、4.2）
- 运行温度 75 ℃ > 额定上限 70 ℃，触发 4.1。
- 24h 告警 3 次 ≥ 3 次，同时触发 4.2。
- 结论：两条并列为触发条款，判**需检修**。

### SV-504 —— 需检修（触发 4.1）
- 运行温度 75 ℃ > 额定上限 70 ℃，触发 4.1。
- 24h 告警 2 次 < 3 次，4.2 不触发。
- 结论：仅因温度超限判**需检修**。（与 SV-503 同温，差别仅在告警次数，故触发条款不同。）

### SV-505 —— 无需检修（无触发条款）
- 该行**有**额定温度上限 88 ℃，故以 88 ℃ 为准，不适用 GPU 机柜限值 80 ℃。
- 运行温度 85 ℃ 虽高于机柜级限值 80 ℃，但未超过本机额定上限 88 ℃，4.1 不触发。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 结论：判**无需检修**。

### SV-506 —— 不适用（触发 4.3）
- 状态为「厂商保修返修中」，按 4.3 不纳入本次判定，直接判**不适用**。
- 其运行温度 95 ℃ 虽 > 额定上限 88 ℃（形式上触发 4.1），但 4.3 为排除条款、优先级最高，该设备本次不作检修判定，超温情况仅作背景记录、随报修一并反馈厂商。

### SV-507 —— 需检修（同时触发 4.1、4.2）
- 该行「额定温度上限」为空，按缺省规则取**高密度 GPU 机柜限值 80 ℃**。
- 运行温度 81 ℃ > 80 ℃，触发 4.1。
- 24h 告警 5 次 ≥ 3 次，同时触发 4.2。
- 结论：判**需检修**。

### SV-508 —— 无需检修（无触发条款）
- 运行温度 66 ℃，**等于**额定上限 66 ℃。4.1 的判据是「超过」，等于不属于超过，4.1 不触发。
- 24h 告警 0 次 < 3 次。
- 结论：判**无需检修**。

### SV-509 —— 需检修（触发 4.1）
- 运行温度 67 ℃ > 额定上限 66 ℃，触发 4.1。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 结论：判**需检修**。（与 SV-508 同型号限值，仅高 1 ℃，即构成超限。）

## 四、需重点跟进

- **SV-503、SV-504、SV-509**：温度超限，其中 SV-503、SV-504 超限 5 ℃，建议优先安排。
- **SV-501、SV-507**：告警次数达标（3 次、5 次），SV-507 同时温度超限，风险较高。
- **SV-506**：本次判「不适用」是**程序排除**，不代表设备正常——其温度已达 95 ℃，请在报修时向厂商明确说明。
- 共 5 台需检修（SV-501、SV-503、SV-504、SV-507、SV-509），3 台无需检修（SV-502、SV-505、SV-508），1 台不适用（SV-506）。
