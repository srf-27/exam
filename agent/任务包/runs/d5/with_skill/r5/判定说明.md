# 机房设备停机检修判定说明

- 判定依据：`设备维护规范.md` v3.2 第 4 节
- 数据来源：`巡检数据.csv`
- 判定日期：2026-09-29
- 结论值域：需检修 / 无需检修 / 不适用

## 判定规则与顺序

| 条款 | 触发条件 | 结论 |
| --- | --- | --- |
| 4.3 | 状态为「厂商保修返修中」 | 不适用（不纳入本次判定，优先于 4.1/4.2） |
| 4.2 | 24 小时内告警 ≥3 次，无论温度是否超限 | 需检修 |
| 4.1 | 运行温度**超过**额定温度上限 | 需检修 |
| 4.1 缺省 | 额定温度上限为空时，按机柜级限值执行 | 通用计算机柜 62 ℃；高密度 GPU 机柜 80 ℃ |

两条要点：

1. **4.3 是排除条款**，先于温度、告警判定。命中即判「不适用」，不再看其它指标。
2. **「超过」为严格大于**，运行温度等于限值不算超限；限值为空时走机柜级回退，回退值取决于该行「机柜用途」。

- 温度核验：该行额定温度上限为空，按机柜用途「通用计算」回退为 62 ℃；运行温度 60 ℃ 未超过，温度本身不构成触发。
- 结论由 4.2 单独成立。
