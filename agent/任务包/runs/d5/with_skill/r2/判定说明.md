# 机房设备检修判定说明

依据《机房设备维护规范 v3.2（现行）》第 4 节，对本月巡检数据（`巡检数据.csv`）逐台判定，结果已填回 `检修判定表.csv`。

## 一、判定依据（从规范挖出的约束清单）

| 条款 | 条件 | 结论 |
|---|---|---|
| 4.1 | 运行温度 **超过** 额定温度上限 | 需检修 |
| 4.1（回退缺省） | 「额定温度上限」列为空时，改用**机柜级限值**：通用计算机柜 **62 ℃**，高密度 GPU 机柜 **80 ℃** | —— |
| 4.2 | 24h 告警 **≥3 次**，无论温度是否超限 | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定 → **不适用** |

**判定顺序**：先看 4.3（排除规则，「不纳入本次判定」），命中即判「不适用」；未命中的设备再看 4.1 与 4.2，两条任一条命中即「需检修」（同时命中则两条都记录）；两条都不命中才判「无需检修」。

两点边界：
- 4.1 用的词是「超过」，故温度**等于**上限不算超限；
- 4.2 用的是「≥3 次」，故恰好 3 次即触发。

## 二、逐台说明

**SV-501｜需检修｜触发 4.2**
额定温度上限为空，机柜为通用计算 → 回退到机柜级限值 62 ℃。运行温度 60 ℃ 未超过 62 ℃，4.1 未触发；但 24h 告警 3 次，达到「≥3 次」，触发 4.2，故需检修。

**SV-502｜无需检修｜无**
同为通用计算、额定上限为空 → 限值 62 ℃。运行 60 ℃ 未超限；告警 0 次 < 3 次；状态在用。4.1、4.2 均未触发。

**SV-503｜需检修｜触发 4.1、4.2**
额定上限 70 ℃，运行 75 ℃，超过上限，触发 4.1；24h 告警 3 次也达到「≥3 次」，同时触发 4.2。两条都命中，均记录。

**SV-504｜需检修｜触发 4.1**
额定上限 70 ℃，运行 75 ℃，超过上限，触发 4.1；告警 2 次 < 3 次，4.2 未触发。

**SV-505｜无需检修｜无**
高密度 GPU 机柜，额定上限 88 ℃，运行 85 ℃ 未超限；告警 0 次 < 3 次。4.1、4.2 均未触发。

**SV-506｜不适用｜触发 4.3**
状态为「厂商保修返修中」。按 4.3，该设备不纳入本次判定，判「不适用」。虽然其运行温度 95 ℃ 已超过额定上限 88 ℃，但排除规则优先，温度与告警值不再参与判定。

**SV-507｜需检修｜触发 4.1、4.2**
额定温度上限为空，机柜为高密度 GPU → 回退到机柜级限值 80 ℃。运行温度 81 ℃ 超过 80 ℃，触发 4.1；24h 告警 5 次 ≥3 次，同时触发 4.2。

**SV-508｜无需检修｜无**
额定上限 66 ℃，运行温度 66 ℃。规范用词为「超过」，等于上限不属于超过，4.1 未触发；告警 0 次 < 3 次，4.2 也未触发。这是本批里唯一贴着上限但按字面判无需检修的行。

**SV-509｜需检修｜触发 4.1**
额定上限 66 ℃，运行温度 67 ℃，超过上限，触发 4.1；告警 0 次 < 3 次，4.2 未触发。与 SV-508 仅 1 ℃ 之差，但已越限。

## 三、汇总

- 需检修：SV-501、SV-503、SV-504、SV-507、SV-509（5 台）
- 无需检修：SV-502、SV-505、SV-508（3 台）
- 不适用：SV-506（1 台）

## 四、需要提醒的两点

1. **空值回退是关键**：SV-501、SV-502、SV-507 三台的「额定温度上限」列为空，若漏掉 4.1 的回退条款会无从判起。这三台均按「机柜用途」映射到机柜级限值（通用计算 62 ℃ / 高密度 GPU 80 ℃）。
2. **SV-506 的 95 ℃ 是干扰项**：它温度严重超限，但状态为厂商保修返修中，按 4.3 排除，报修时不要把它当故障设备统计。
