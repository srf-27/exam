# 机房设备检修判定说明

- 规范依据：《机房设备维护规范 v3.2》第 4 章
- 数据依据：`巡检数据.csv`
- 判定日期：2026-09-29

## 一、判据口径

**4.1 温度超限**：运行温度 **严格大于** 额定温度上限即判需检修。
- 额定温度上限为空的行，回退到机柜级限值：通用计算机柜 **62 ℃**、高密度 GPU 机柜 **80 ℃**。
- 等于限值不算超限（边界取「超过」的字面含义）。

**4.2 告警次数**：24 小时内告警 **≥3 次** 一律判需检修，与温度是否超限无关。

**4.3 状态排除**：状态为「厂商保修返修中」的设备不纳入本次判定，判「不适用」——即使其温度或告警本身已触及其它条款。

优先级：先看 4.3 是否排除，未被排除的再按 4.1 / 4.2 判定，两条命中则并列填写。

## 二、逐台说明

### SV-501 — 需检修（触发 4.2）
A-01 机柜、通用计算，额定温度上限为空，故取机柜级限值 62 ℃。
- 温度：60 ℃ ≤ 62 ℃，**未超限**，4.1 不触发。
- 告警：24h 内 3 次，**≥3 次**，4.2 触发。

结论：温度虽正常，但告警达阈值，判**需检修**。这是本表中「仅因告警次数被判修」的设备。

### SV-502 — 无需检修
A-01 机柜、通用计算，额定上限为空，取机柜级限值 62 ℃。
- 温度：60 ℃ ≤ 62 ℃，未超限。
- 告警：0 次 < 3 次，未触发。

结论：两项判据均未触发，判**无需检修**。

### SV-503 — 需检修（触发 4.1、4.2）
A-02 机柜、通用计算，额定上限 70 ℃（非空，按本行值执行）。
- 温度：75 ℃ **＞** 70 ℃，超限 5 ℃，4.1 触发。
- 告警：24h 内 3 次，≥3 次，4.2 同时触发。

结论：两条判据均命中，判**需检修**。

### SV-504 — 需检修（触发 4.1）
与 SV-503 同机柜、同温度（75 ℃），额定上限 70 ℃。
- 温度：75 ℃ ＞ 70 ℃，4.1 触发。
- 告警：2 次 < 3 次，4.2 不触发。

结论：虽告警未达阈值，但温度超限，仍判**需检修**。与 SV-503 的区别仅在告警次数，不影响结论。

### SV-505 — 无需检修
B-01 机柜、高密度 GPU，额定上限 **88 ℃**（有显式值，按 88 ℃ 判，不套用机柜级 80 ℃）。
- 温度：85 ℃ ≤ 88 ℃，未超限。
- 告警：0 次 < 3 次，未触发。

结论：判**无需检修**。

### SV-506 — 不适用（触发 4.3）
B-01 机柜、高密度 GPU，额定上限 88 ℃，运行温度 95 ℃，告警 0 次。
- 若按 4.1 衡量：95 ℃ ＞ 88 ℃，本应判需检修。
- 但状态为「厂商保修返修中」，依 4.3 不纳入本次判定。

结论：判**不适用**，交由厂商返修流程处理，不进入本月报修清单。

### SV-507 — 需检修（触发 4.1、4.2）
B-02 机柜、高密度 GPU，额定温度上限**为空**，故回退到高密度 GPU 机柜级限值 **80 ℃**（不是 88 ℃）。
- 温度：81 ℃ **＞** 80 ℃，超限 1 ℃，4.1 触发。
- 告警：24h 内 5 次，≥3 次，4.2 触发。

结论：判**需检修**。此台的关键在于空值回退——若误用 88 ℃ 会漏判。

### SV-508 — 无需检修
C-01 机柜、通用计算，额定上限 66 ℃，运行温度 66 ℃。
- 温度：66 ℃ **等于** 66 ℃，未「超过」限值，4.1 不触发。
- 告警：0 次 < 3 次，未触发。

结论：判**无需检修**。属边界情形，等于限值不作超限处理；若后续温度再升 1 ℃ 即触判。

### SV-509 — 需检修（触发 4.1）
C-02 机柜、通用计算，额定上限 66 ℃，运行温度 67 ℃。
- 温度：67 ℃ ＞ 66 ℃，超限 1 ℃，4.1 触发。
- 告警：0 次 < 3 次，未触发。

结论：判**需检修**。与 SV-508 同为 66 ℃ 限值机柜，仅 1 ℃ 之差即跨越判据。

## 四、需留意的判定要点

1. **空值回退**：SV-501、SV-502、SV-507 三台额定上限为空，按机柜用途取限值（通用计算 62 ℃ / 高密度 GPU 80 ℃）。
2. **显式值优先**：SV-505 同为高密度 GPU 机柜但表中有显式上限 88 ℃，按 88 ℃ 判，不套用机柜级 80 ℃。
3. **严格大于**：SV-508 的 66 ℃ 等于限值，不判超限。
4. **4.3 优先排除**：SV-506 温度已超限，仍因状态判「不适用」。
