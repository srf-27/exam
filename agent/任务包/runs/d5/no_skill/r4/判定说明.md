# 机房设备巡检判定说明

判定依据：《机房设备维护规范 v3.2》第 4 节「停机检修判据」。

- **4.1** 运行温度超过额定温度上限的，判为需检修；额定温度上限列为空的设备，按机柜级限值执行（通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃）。
- **4.2** 24 小时内告警 ≥3 次的，无论温度是否超限，均判为需检修。
- **4.3** 状态为「厂商保修返修中」的设备不纳入本次判定，判为「不适用」。

本次共 9 台设备：需检修 4 台，无需检修 4 台，不适用 1 台。

---

## SV-501　判定：需检修

- 机柜 A-01（通用计算），额定温度上限列为空 → 按机柜级限值 **62 ℃** 执行。
- 运行温度 60 ℃，未超过 62 ℃，**4.1 不触发**。
- 24h 告警 **3 次**，达到 ≥3 次阈值，**4.2 触发**。
- 结论：温度虽正常，但按 4.2 仍判为需检修。**触发条款 4.2**。

## SV-502　判定：无需检修

- 机柜 A-01（通用计算），额定温度上限列为空 → 按机柜级限值 **62 ℃** 执行。
- 运行温度 60 ℃ ≤ 62 ℃，4.1 不触发。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 结论：无任何条款触发。**触发条款：无**。

## SV-503　判定：需检修

- 机柜 A-02（通用计算），额定温度上限 **70 ℃**。
- 运行温度 75 ℃ > 70 ℃，**4.1 触发**。
- 24h 告警 3 次，达到 ≥3 次阈值，**4.2 同时触发**。
- 结论：温度超限且告警达到阈值，两项条款均触发。**触发条款 4.1、4.2**。

## SV-504　判定：需检修

- 机柜 A-02（通用计算），额定温度上限 **70 ℃**。
- 运行温度 75 ℃ > 70 ℃，**4.1 触发**。
- 24h 告警 2 次 < 3 次，4.2 不触发（但 4.1 已足以判定）。
- 结论：仅因温度超限判为需检修。**触发条款 4.1**。

## SV-505　判定：无需检修

- 机柜 B-01（高密度 GPU），额定温度上限 **88 ℃**。
- 运行温度 85 ℃ ≤ 88 ℃，4.1 不触发。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 结论：温度、告警均在限值内。**触发条款：无**。

## SV-506　判定：不适用

- 状态为「厂商保修返修中」，按 **4.3** 不纳入本次判定。
- 说明：该设备运行温度 95 ℃ 虽已超过额定上限 88 ℃，但因设备正处于厂商保修返修中，本次不作检修判定，直接判为「不适用」。
- 结论：**触发条款 4.3**（不适用）。

## SV-507　判定：需检修

- 机柜 B-02（高密度 GPU），额定温度上限列为空 → 按机柜级限值 **80 ℃** 执行。
- 运行温度 81 ℃ > 80 ℃，**4.1 触发**。
- 24h 告警 5 次，达到 ≥3 次阈值，**4.2 同时触发**。
- 结论：温度超限且告警达到阈值。**触发条款 4.1、4.2**。

## SV-508　判定：无需检修

- 机柜 C-01（通用计算），额定温度上限 **66 ℃**（该行有明确限值，不适用机柜级 62 ℃）。
- 运行温度 66 ℃，**等于** 66 ℃。规范用词为「超过」，66 未超过 66，故 4.1 不触发。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 结论：处于限值边界但未超限。**触发条款：无**。

## SV-509　判定：需检修

- 机柜 C-02（通用计算），额定温度上限 **66 ℃**。
- 运行温度 67 ℃ > 66 ℃，**4.1 触发**。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 结论：仅因温度超限判为需检修。**触发条款 4.1**。

## 判定汇总

| 设备编号 | 判定 | 触发条款 | 关键数值 |
|---|---|---|---|
| SV-501 | 需检修 | 4.2 | 告警 3 次；60 ℃ ≤ 62 ℃ |
| SV-502 | 无需检修 | 无 | 60 ℃ ≤ 62 ℃；告警 0 次 |
| SV-503 | 需检修 | 4.1、4.2 | 75 ℃ > 70 ℃；告警 3 次 |
| SV-504 | 需检修 | 4.1 | 75 ℃ > 70 ℃；告警 2 次 |
| SV-505 | 无需检修 | 无 | 85 ℃ ≤ 88 ℃；告警 0 次 |
| SV-506 | 不适用 | 4.3 | 厂商保修返修中 |
| SV-507 | 需检修 | 4.1、4.2 | 81 ℃ > 80 ℃；告警 5 次 |
| SV-508 | 无需检修 | 无 | 66 ℃ = 66 ℃；告警 0 次 |
| SV-509 | 需检修 | 4.1 | 67 ℃ > 66 ℃；告警 0 次 |

## 两点判定说明

1. **限值取值**：只有当「额定温度上限」列为空时，才回退到机柜级限值。SV-501、SV-507 属该情形；SV-508、SV-509 行内已给出 66 ℃，故按 66 ℃ 判定，不采用通用机柜的 62 ℃。
2. **「超过」为严格大于**：SV-508 的 66 ℃ 等于上限，不构成超限；SV-509 的 67 ℃ 才超过。
