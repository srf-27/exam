# 机房设备检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 节停机检修判据；数据来源：`巡检数据.csv`（2026-09 巡检）。
- 判定口径：
  - **4.1** 运行温度**超过**额定温度上限 → 需检修。"超过"按严格大于（`>`）执行，等于上限不算超限。额定温度上限列**为空**的设备，改用其机柜级限值：**通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃**；该列非空时以行内额定值为准，不再套用机柜级限值。
  - **4.2** 24 小时内告警 **≥3 次** → 需检修，与温度是否超限无关。
  - **4.3** 状态为「厂商保修返修中」→ **不适用**，不纳入本次判定（优先于 4.1/4.2）。
  - 4.1 与 4.2 可同时触发，触发条款栏两者并列填写。

---

## 逐台说明

### SV-501 — 需检修
- 机柜 A-01（通用计算），额定温度上限列为空 → 按机柜级限值 **62 ℃**。
- 运行温度 60 ℃，未超过 62 ℃，**4.1 不触发**。
- 24h 告警 3 次，**≥3 次，4.2 触发**。
- 判定：需检修。

### SV-502 — 无需检修
- 机柜 A-01（通用计算），额定列为空 → 限值 62 ℃。
- 运行温度 60 ℃ ≤ 62 ℃，未超限；24h 告警 0 次 < 3 次。
- 4.1、4.2 均不触发。
- 判定：无需检修。

### SV-503 — 需检修
- 额定温度上限 70 ℃，运行温度 75 ℃，75 > 70，**4.1 触发**。
- 24h 告警 3 次，**≥3 次，4.2 同时触发**。
- 两条独立判据均成立，触发条款记为 4.1、4.2。
- 判定：需检修。

### SV-504 — 需检修
- 额定温度上限 70 ℃，运行温度 75 ℃，75 > 70，**4.1 触发**。
- 24h 告警 2 次 < 3 次，4.2 不触发。
- 判定：需检修。

### SV-505 — 无需检修
- 额定温度上限 88 ℃，运行温度 85 ℃，85 ≤ 88，未超限。
- 24h 告警 0 次 < 3 次。
- 4.1、4.2 均不触发。
- 判定：无需检修。

### SV-506 — 不适用
- 状态为「厂商保修返修中」，**4.3 触发**，不纳入本次停机检修判定。
- 说明：该机运行温度 95 ℃ 虽已超过其额定上限 88 ℃（本可触发 4.1），但按 4.3 规定整台设备判为「不适用」，温度与告警不再作为本次判据。该机由厂商保修返修流程处理。
- 判定：不适用。

### SV-507 — 需检修
- 机柜 B-02（高密度 GPU），额定列为空 → 按机柜级限值 **80 ℃**。
- 运行温度 81 ℃，81 > 80，**4.1 触发**（注意：若误按通用机柜 62 ℃ 或按同排 88 ℃ 处理均会得出不同结论，此处按规范取高密度 GPU 机柜限值 80 ℃）。
- 24h 告警 5 次，**≥3 次，4.2 同时触发**。
- 判定：需检修。

### SV-508 — 无需检修
- 额定温度上限 66 ℃（行内额定值非空，按行内值执行，不再套用通用机柜 62 ℃ 限值）。
- 运行温度 66 ℃，等于上限，**未超过**（4.1 按严格大于执行），不触发。
- 24h 告警 0 次 < 3 次。
- 判定：无需检修。

### SV-509 — 需检修
- 额定温度上限 66 ℃，运行温度 67 ℃，67 > 66，**4.1 触发**。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- 判定：需检修。

## 易错点备忘（本次判定中做过明确取舍的地方）

1. **SV-508 / SV-509**：机柜用途为"通用计算"，但行内额定温度上限为 66 ℃（非空）。按 4.1，额定列非空时以行内额定值为准，故不套用通用机柜 62 ℃ 限值。66 ℃ 恰等于上限，属"未超过"。
2. **SV-507**：额定列为空，但机柜用途是高密度 GPU，须用 80 ℃ 而非通用机柜的 62 ℃。81 ℃ 仅以 1 ℃ 之差超限。
3. **SV-506**：温度（95 ℃ > 88 ℃）与告警虽可能触发 4.1，但 4.3 对状态为"厂商保修返修中"的设备一律判"不适用"，温度/告警判据不再适用。
4. **SV-501 / SV-502**：额定列为空，机柜 A-01 为通用计算，取机柜级限值 62 ℃；两台运行温度均为 60 ℃，均未超限，区别仅在告警次数。
