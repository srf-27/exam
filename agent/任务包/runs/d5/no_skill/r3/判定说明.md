# 机房设备检修判定说明

依据：《机房设备维护规范 v3.2》第 4 章「停机检修判据」；数据来源：`巡检数据.csv`。

## 判定规则摘要

- **4.1**　运行温度 > 额定温度上限 → 需检修。额定温度上限以巡检数据表对应行为准；**该列为空的设备，按其机柜级限值执行**：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。
- **4.2**　24 小时内告警 **≥ 3 次** → 需检修，无论温度是否超限。
- **4.3**　状态为「厂商保修返修中」→ 不纳入本次判定，判为「不适用」（优先级最高，即使温度或告警触及其他条款）。

- **SV-501　需检修（4.2）**：额定温度上限为空，按通用计算机柜机柜级限值 62 ℃，运行温度 60 ℃ **未超限**；但 24h 告警 3 次，达到「≥3 次」，据 4.2 判需检修。
- **SV-502　无需检修**：额定温度上限为空，按机柜级限值 62 ℃，运行温度 60 ℃ 未超限；告警 0 次。不触发任何条款。
- **SV-503　需检修（4.1、4.2）**：运行温度 75 ℃ 超过额定上限 70 ℃，触发 4.1；且 24h 告警 3 次，同时触发 4.2。
- **SV-504　需检修（4.1）**：运行温度 75 ℃ 超过额定上限 70 ℃，触发 4.1；告警 2 次（< 3 次），不触发 4.2，但温度已足以判需检修。
- **SV-505　无需检修**：运行温度 85 ℃ 未超过额定上限 88 ℃；告警 0 次。不触发任何条款。
- **SV-506　不适用（4.3）**：状态为「厂商保修返修中」，据 4.3 不纳入本次判定。注：其运行温度 95 ℃ 虽已超过额定上限 88 ℃，但因 4.3 优先，本次不判「需检修」，返修完成后应重新巡检判定。
- **SV-507　需检修（4.1、4.2）**：额定温度上限为空，按高密度 GPU 机柜机柜级限值 80 ℃，运行温度 81 ℃ 超过该限值，触发 4.1；且 24h 告警 5 次，同时触发 4.2。
- **SV-508　无需检修**：运行温度 66 ℃ 与额定上限 66 ℃ **相等，未「超过」**，不触发 4.1；告警 0 次。判无需检修（属临界值，建议下次巡检重点关注）。
- **SV-509　需检修（4.1）**：运行温度 67 ℃ 超过额定上限 66 ℃，触发 4.1；告警 0 次，不触发 4.2。

## 备注

- 涉及「机柜级限值」的两台设备 **SV-501、SV-502、SV-507** 因额定温度上限列为空，按 4.1 规定以机柜用途对应的限值替代：通用计算 62 ℃、高密度 GPU 80 ℃。
- 边界处理：4.1 为「**超过**上限」，故温度等于上限（SV-508）不判需检修；4.2 为「**≥3 次**」，故恰好 3 次（SV-501、SV-503）即需检修。
