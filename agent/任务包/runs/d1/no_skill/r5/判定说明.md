# 机房设备检修判定说明

**依据规范**：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
**数据来源**：`巡检数据.csv`（2026 年 9 月巡检批次）
**判定时间**：2026-09-29

## 判定规则摘要

| 条款 | 判据 | 结论 |
| --- | --- | --- |
| 4.1 | 运行温度 **超过**额定温度上限 | 需检修 |
| 4.1（补充） | 额定温度上限为空时，按机柜级限值执行：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃ | — |
| 4.2 | 24 小时内告警 **≥3 次**（不论温度是否超限） | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不适用（不纳入本次判定） |

两点口径说明：

- 4.1 为「**超过**」，即运行温度等于上限**不算**超限，必须严格大于才触发。
- 4.3 的适用优先级最高：设备一旦处于「厂商保修返修中」，即不再按 4.1／4.2 判定。

## 逐台判定

### SV-101 → 需检修

- 设备：A-01 机柜，通用计算用途，在用。
- 数值：额定温度上限**为空**，运行温度 64 ℃，24h 告警 0 次。
- 判定：额定上限为空，按 4.1 补充规定套用**通用计算机柜限值 62 ℃**。运行温度 64 ℃ > 62 ℃，超限 2 ℃，触发 **4.1**。
- 告警 0 次，未触发 4.2。

### SV-102 → 无需检修

- 设备：A-02 机柜，通用计算用途，在用。
- 数值：额定温度上限 70 ℃，运行温度 70 ℃，24h 告警 1 次。
- 判定：运行温度 70 ℃ 与上限 70 ℃ **持平，未超过**，不触发 4.1（此处易误判为超限，注意 4.1 是严格大于）。告警 1 次 < 3 次，不触发 4.2。
- 条款均未触发，判为无需检修。**建议**：该机温度已贴上限、无余量，下次巡检应重点关注。

### SV-103 → 无需检修

- 设备：B-01 机柜，高密度 GPU 用途，在用。
- 数值：额定温度上限**为空**，运行温度 79 ℃，24h 告警 0 次。
- 判定：额定上限为空，按 4.1 补充规定套用**高密度 GPU 机柜限值 80 ℃**（不可误用通用机柜的 62 ℃）。运行温度 79 ℃ ≤ 80 ℃，未超限，不触发 4.1。告警 0 次 < 3 次，不触发 4.2。
- 条款均未触发，判为无需检修。**建议**：距限值仅 1 ℃，余量很小，下次巡检应重点关注。

### SV-104 → 需检修

- 设备：B-02 机柜，高密度 GPU 用途，在用。
- 数值：额定温度上限 85 ℃，运行温度 90 ℃，24h 告警 0 次。
- 判定：该设备额定上限非空，直接按其执行。运行温度 90 ℃ > 85 ℃，超限 5 ℃，触发 **4.1**。
- 告警 0 次，未触发 4.2；但温度已超限，不受告警次数影响。

### SV-105 → 需检修

- 设备：C-01 机柜，通用计算用途，在用。
- 数值：额定温度上限 66 ℃，运行温度 60 ℃，24h 告警 5 次。
- 判定：运行温度 60 ℃ ≤ 66 ℃，**温度本身未超限，不触发 4.1**；但 24h 告警 5 次 ≥ 3 次，按 4.2「无论温度是否超限」触发 **4.2**，判为需检修。
- 该机属于典型的「温度正常但告警异常」情形，需排查告警根因。

### SV-106 → 不适用

- 设备：C-02 机柜，通用计算用途，状态**厂商保修返修中**。
- 数值：额定温度上限 66 ℃，运行温度 80 ℃，24h 告警 2 次。
- 判定：状态为「厂商保修返修中」，按 **4.3** 不纳入本次判定，判为**不适用**。
- 说明：若按 4.1 衡量，其运行温度 80 ℃ > 66 ℃ 本会构成超限，但 4.3 优先适用，故本次不作检修判定。该机已在厂商返修流程中，无需另行报修；待返修完成、状态恢复为「在用」后，应重新纳入判定。
