# 机房设备检修判定说明

- 判定依据：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
- 数据来源：巡检数据.csv（本月巡检）
- 判定日期：2026-09-29
- 判定口径：每台设备一行，结论取 **需检修 / 无需检修 / 不适用** 之一

## 判定规则摘要

- **4.1**：运行温度**超过**额定温度上限 → 需检修。额定上限取巡检数据表该行数值；**该列为空时按机柜级限值执行**：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。
- **4.2**：24 小时内告警 **≥3 次** → 需检修（无论温度是否超限）。
- **4.3**：状态为「厂商保修返修中」→ 不适用，不纳入本次判定。

> 注：「超过」按严格大于理解，运行温度**等于**额定上限时不触发 4.1。

## 逐台判定

### SV-101 —— 需检修（触发 4.1）
- 机柜 A-01，用途为通用计算；**额定温度上限一列为空**，故按机柜级限值执行，取通用计算机柜限值 **62 ℃**。
- 运行温度 **64 ℃ > 62 ℃**，超出上限，触发 4.1。
- 24h 告警 0 次，不涉及 4.2。
- 结论：**需检修**。

### SV-102 —— 无需检修
- 额定温度上限 70 ℃，运行温度 **70 ℃**，未超过（等于上限，不触发 4.1）。
- 24h 告警 **1 次 < 3 次**，不触发 4.2。
- 结论：**无需检修**。

### SV-103 —— 无需检修
- 机柜 B-01，用途为高密度 GPU；**额定温度上限一列为空**，故按机柜级限值执行，取高密度 GPU 机柜限值 **80 ℃**。
- 运行温度 **79 ℃ ≤ 80 ℃**，未超限，不触发 4.1。
- 24h 告警 0 次 < 3 次，不触发 4.2。
- 结论：**无需检修**。

### SV-104 —— 需检修（触发 4.1）
- 额定温度上限 85 ℃，运行温度 **90 ℃ > 85 ℃**，超出上限，触发 4.1。
- 24h 告警 0 次，不涉及 4.2。
- 结论：**需检修**。

### SV-105 —— 需检修（触发 4.2）
- 运行温度 **60 ℃ ≤ 额定上限 66 ℃**，未超限，不触发 4.1。
- 24h 告警 **5 次 ≥ 3 次**，触发 4.2，无论温度是否超限均判为需检修。
- 结论：**需检修**。温度虽正常，但告警频次已达标，需停机排查告警根因。

### SV-106 —— 不适用（触发 4.3）
- 状态为「**厂商保修返修中**」，按 4.3 不纳入本次判定。
- 其运行温度 80 ℃、24h 告警 2 次的记录仅作留档，不作为本月判定依据。
- 结论：**不适用**。该设备应走厂商保修返修流程，不在本次报修范围内。
