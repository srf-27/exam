# 机房设备检修判定说明

本次判定依据《机房设备维护规范 v3.2》第 4 节「停机检修判据」，数据来源为《巡检数据.csv》本月巡检结果。

## 判据要点

- **4.1 温度超限**：运行温度**超过**额定温度上限即需检修。额定温度上限为空时，改按机柜级限值执行——通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。注意「超过」为严格大于，运行温度**等于**上限不构成超限。
- **4.2 告警频次**：24 小时内告警 **≥3 次**的，无论温度是否超限，均需检修。
- **4.3 返修设备**：状态为「厂商保修返修中」的设备不纳入本次判定，判为「不适用」。

## 逐台判定

### SV-101 —— 需检修（触发 4.1）
- 机柜 A-01，通用计算，运行温度 64 ℃，24h 告警 0 次。
- 该行**额定温度上限为空**，依 4.1 按其机柜级限值执行：通用计算机柜限值 62 ℃。
- 64 ℃ > 62 ℃，运行温度超过限值，判**需检修**。

### SV-102 —— 无需检修
- 机柜 A-02，通用计算，额定温度上限 70 ℃，运行温度 70 ℃，24h 告警 1 次。
- 温度：70 ℃ 未**超过** 70 ℃（等于不算超过），4.1 不触发。
- 告警：1 次 < 3 次，4.2 不触发。
- 两项判据均未触发，判**无需检修**。运行温度已顶到上限，建议下月巡检重点关注其温度走势。

### SV-103 —— 无需检修
- 机柜 B-01，高密度 GPU，运行温度 79 ℃，24h 告警 0 次。
- 该行**额定温度上限为空**，依 4.1 按其机柜级限值执行：高密度 GPU 机柜限值 80 ℃。
- 79 ℃ 未超过 80 ℃，4.1 不触发；告警 0 次 < 3 次，4.2 不触发。
- 判**无需检修**。距限值仅 1 ℃，余量偏小，建议关注散热。

### SV-104 —— 需检修（触发 4.1）
- 机柜 B-02，高密度 GPU，额定温度上限 85 ℃，运行温度 90 ℃，24h 告警 0 次。
- 90 ℃ > 85 ℃，运行温度超过额定温度上限，判**需检修**。虽无告警，但 4.1 为温度单一判据，告警为 0 不影响结论。

### SV-105 —— 需检修（触发 4.2）
- 机柜 C-01，通用计算，额定温度上限 66 ℃，运行温度 60 ℃，24h 告警 5 次。
- 温度：60 ℃ 未超过 66 ℃，4.1 不触发。
- 告警：5 次 ≥ 3 次，触发 4.2，无论温度是否超限均需检修，判**需检修**。温度正常而告警频繁，建议排查告警根因（如电源、网络或部件亚健康）。

### SV-106 —— 不适用（触发 4.3）
- 机柜 C-02，通用计算，额定温度上限 66 ℃，运行温度 80 ℃，24h 告警 2 次，状态为「厂商保修返修中」。
- 依 4.3，状态为「厂商保修返修中」的设备不纳入本次判定，判**不适用**。该条优先于 4.1、4.2 适用，故此处虽温度超限亦不作检修判定，其处置随厂商保修流程。

## 汇总

| 设备编号 | 判定 | 触发条款 | 关键依据 |
|---|---|---|---|
| SV-101 | 需检修 | 4.1 | 64 ℃ > 机柜级限值 62 ℃ |
| SV-102 | 无需检修 | 无 | 70 ℃ 未超过 70 ℃；告警 1 次 < 3 次 |
| SV-103 | 无需检修 | 无 | 79 ℃ 未超过机柜级限值 80 ℃；告警 0 次 < 3 次 |
| SV-104 | 需检修 | 4.1 | 90 ℃ > 额定上限 85 ℃ |
| SV-105 | 需检修 | 4.2 | 告警 5 次 ≥ 3 次 |
| SV-106 | 不适用 | 4.3 | 厂商保修返修中，不纳入判定 |

需检修共 3 台：SV-101、SV-104、SV-105；无需检修 2 台：SV-102、SV-103；不适用 1 台：SV-106。
