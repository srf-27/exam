# 机房设备检修判定说明

- 依据规范：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
- 依据数据：`巡检数据.csv`（2026 年 9 月巡检）
- 判定口径：每台设备一行，取「需检修 / 无需检修 / 不适用」三者之一
- 相关条款：
  - 4.1　运行温度超过额定温度上限的，判为需检修；**额定温度上限列为空的，按机柜级限值执行**（通用计算机柜 62℃，高密度 GPU 机柜 80℃）。
  - 4.2　24h 内告警 ≥3 次的，无论温度是否超限，均判为需检修。
  - 4.3　状态为「厂商保修返修中」的设备不纳入本次判定，判为不适用。

---

## 逐台说明

### SV-101　→　需检修
- 机柜 A-01（通用计算），额定温度上限列为**空**，故按机柜级限值执行。
- 通用计算类机柜级限值 **62℃**，本次运行温度 **64℃**，64 > 62，超过限值。
- 触发条款：**4.1**。
- （24h 告警 0 次，不涉及 4.2。）

### SV-102　→　无需检修
- 额定温度上限 **70℃**，运行温度 **70℃**。规范 4.1 的表述为「超过」，70 未超过 70，温度不构成触发。
- 24h 告警 **1 次**，小于 3 次，不构成 4.2 触发。
- 无触发条款。
- 特此说明：该台温度恰好压在上限，属临界但不超限，故判无需检修；建议后续巡检关注其温度趋势。

### SV-103　→　无需检修
- 机柜 B-01（高密度 GPU），额定温度上限列为**空**，故按机柜级限值执行。
- 高密度 GPU 机柜级限值 **80℃**，本次运行温度 **79℃**，79 < 80，未超限。
- 24h 告警 **0 次**，不构成 4.2 触发。
- 无触发条款。
- 特此说明：该台余量仅 1℃，同样处于临界区间，建议留意。

### SV-104　→　需检修
- 额定温度上限 **85℃**，运行温度 **90℃**，90 > 85，超过限值。
- 触发条款：**4.1**。
- （24h 告警 0 次，不涉及 4.2。）

### SV-105　→　需检修
- 温度方面：额定上限 **66℃**，运行温度 **60℃**，未超过限值，**不触发 4.1**。
- 告警方面：24h 告警 **5 次**，≥3 次。
- 规范 4.2 明确「无论温度是否超限」，故温度合格不影响本判定。
- 触发条款：**4.2**。

### SV-106　→　不适用
- 状态为**厂商保修返修中**，按 4.3 不纳入本次判定，判为不适用。
- 触发条款：**4.3**。
- 特此说明：该台运行温度 80℃ 已超其额定上限 66℃，但设备在保修返修流程中，本次不作检修判定，故不据此判「需检修」；待返修完成、状态恢复「在用」后应重新纳入判定。
