# 检修判定说明

依据《机房设备维护规范 v3.2》第 4 节，对 2026-09 巡检数据（`巡检数据.csv`，6 台设备）逐台判定，结果已填入 `检修判定表.csv`。

## 一、判定所依据的规范条款

| 条款 | 条件 | 结论 |
|---|---|---|
| 4.1 | 运行温度 **超过** 额定温度上限 | 需检修 |
| 4.1（缺省） | 额定温度上限列为空时 | 按该设备所在机柜的**机柜级限值**执行：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃ |
| 4.2 | 24 小时内告警 **≥3 次** | 需检修，**无论温度是否超限** |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定，判为**不适用** |

判定顺序：先适用 4.3 的排除规则（该条明确「不纳入本次判定」），被排除的设备不再走 4.1、4.2；其余设备依次核对 4.1、4.2，命中任一条即为需检修。

两点口径说明：

- 「超过」按严格大于理解，运行温度**等于**额定上限不算超限。
- 「额定温度上限」一列允许为空，为空时回退到机柜级限值。回退时按巡检数据表的「机柜用途」列区分通用计算机柜与高密度 GPU 机柜。本批数据中 SV-101、SV-103 两台的该列为空。

## 二、逐台判定

### SV-101 — 需检修（4.1）
机柜 A-01，用途通用计算，额定温度上限列为空。按缺省规则取通用计算机柜限值 62 ℃。运行温度 64 ℃ > 62 ℃，超限，触发出 4.1。24h 告警 0 次，不触发 4.2。

### SV-102 — 无需检修
额定温度上限 70 ℃，运行温度 70 ℃。70 未**超过** 70（等于不算超过），不触发 4.1。24h 告警 1 次 < 3 次，不触发 4.2。两条判据均不命中。

### SV-103 — 无需检修
机柜 B-01，用途高密度 GPU，额定温度上限列为空。按缺省规则取高密度 GPU 机柜限值 80 ℃。运行温度 79 ℃ ≤ 80 ℃，不触发 4.1。24h 告警 0 次 < 3 次，不触发 4.2。

### SV-104 — 需检修（4.1）
额定温度上限 85 ℃，运行温度 90 ℃。90 > 85，超限，触发 4.1。24h 告警 0 次，不涉及 4.2。

### SV-105 — 需检修（4.2）
额定温度上限 66 ℃，运行温度 60 ℃。60 ≤ 66，温度未超限，**不**触发 4.1。但 24h 告警 5 次 ≥ 3 次，4.2 规定不论温度是否超限均判需检修，故判需检修。本台是「温度正常但因告警触发」的情形。

### SV-106 — 不适用（4.3）
状态为「厂商保修返修中」，按 4.3 不纳入本次判定，直接判为**不适用**。其运行温度 80 ℃ > 额定 66 ℃，单看 4.1 本应判需检修，但因 4.3 的排除规则优先，该超限事实不作检修结论，也不列触发条款。待返修完成、状态恢复后再纳入下一轮判定。
