# 机房巡检判定说明

依据：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
数据：《巡检数据.csv》（6 台设备，未作修改）
判定值域：需检修 / 无需检修 / 不适用

## 一、判定规则与执行顺序

按规范挖出的硬约束共 4 条（含 1 条回退规则）：

| 编号 | 条款 | 条件 | 结论 |
|---|---|---|---|
| R1 | 4.1 | 运行温度 **超过**（严格大于）额定温度上限 | 需检修 |
| R2 | 4.1 回退 | 额定温度上限列为空时，按其机柜级限值执行：通用计算机柜 62℃，高密度 GPU 机柜 80℃ | （用于 R1 取限值） |
| R3 | 4.2 | 24h 告警次数 **≥3 次**，无论温度是否超限 | 需检修 |
| R4 | 4.3 | 状态为「厂商保修返修中」 | 不适用（不纳入本次判定） |

执行顺序（由数据中的冲突行校准）：

1. **先判 R4（排除）**：状态为「厂商保修返修中」的直接判「不适用」，不再看温度与告警。依据是 4.3 的措辞「**不纳入本次判定**」——它把该设备移出本次判定范围，效力高于 4.1 / 4.2。
2. **再判 R3（告警）**：不属排除范围时，24h 告警 ≥3 次即需检修，4.2 明示「无论温度是否超限」，故温度正常也要修。
3. **再判 R1（温度）**：未命中 R3 时，看运行温度是否**严格大于**限值；额定上限列为空则按 R2 取机柜级限值。
4. 以上均不命中 → **无需检修**。

## 二、逐台说明

### SV-101　→ 需检修（触发 4.1）
- 机柜 A-01，用途「通用计算」，额定温度上限列为**空**，触发回退规则 R2：按通用计算机柜限值 **62℃**。
- 运行温度 **64℃ > 62℃**，超过限值，命中 4.1。
- 24h 告警 0 次，不涉及 4.2。
- 结论：需检修。**依据数值：限值 62℃（回退推得）、实测 64℃。**

### SV-102　→ 无需检修（未触发任何条款）
- 额定温度上限 **70℃**，运行温度 **70℃**。4.1 的表述是「**超过**」，等于上限不算超过，故**不触发** 4.1。
- 24h 告警 1 次 < 3 次，不触发 4.2。
- 结论：无需检修。**依据数值：限值 70℃（记录给）、实测 70℃（恰等于限值）；告警 1 次。** 这是本表的边界行，判「超过」时为严格大于，不可按 ≥ 处理。

### SV-103　→ 无需检修（未触发任何条款）
- 机柜 B-01，用途「高密度 GPU」，额定温度上限列为**空**，触发回退规则 R2：按高密度 GPU 机柜限值 **80℃**（而非通用机柜的 62℃）。
- 运行温度 **79℃**，未超过 80℃，不触发 4.1。
- 24h 告警 0 次 < 3 次，不触发 4.2。
- 结论：无需检修。**依据数值：限值 80℃（回退推得，按机柜用途取值）、实测 79℃。**

### SV-104　→ 需检修（触发 4.1）
- 额定温度上限 **85℃**，运行温度 **90℃**，**90℃ > 85℃**，命中 4.1。
- 24h 告警 0 次，不涉及 4.2。
- 结论：需检修。**依据数值：限值 85℃（记录给）、实测 90℃。**

### SV-105　→ 需检修（触发 4.2）
- 24h 告警 **5 次 ≥ 3 次**，命中 4.2；4.2 明确「无论温度是否超限」，故温度情况不影响结论。
- 运行温度 60℃ 未超过额定上限 66℃，本不触发 4.1。
- 结论：需检修。**依据数值：告警 5 次（记录给）；温度 60℃ / 限值 66℃（附带核对，非触发原因）。** 本条是「温度正常但告警超标」的行，说明告警是独立触发条件。

### SV-106　→ 不适用（触发 4.3）
- 状态为「**厂商保修返修中**」，命中 4.3 的排除条款，不纳入本次判定。
- **候选结论取舍**：该机运行温度 80℃ **超过**其额定上限 66℃，单看 4.1 应判「需检修」；告警 2 次 < 3 次不涉及 4.2。但 4.3 规定此类设备「不纳入本次判定」，效力优先于 4.1，故最终判「不适用」，不判「需检修」。
- 结论：不适用。**依据数值：状态=厂商保修返修中（记录给）；温度 80℃ / 限值 66℃（仅作取舍说明，已被 4.3 排除）。**
