# 机房设备检修判定说明

- **判定依据**：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- **数据来源**：`巡检数据.csv`（本月巡检数据）
- **判定日期**：2026-09-29
- **结果表**：`检修判定表.csv`

## 一、判定口径

规范 4.1 / 4.2 / 4.3 三条按以下口径执行：

1. **温度限值取值**（4.1）：优先取巡检数据表该行「额定温度上限」；**该列为空时**，才按机柜级限值执行——通用计算机柜 62 ℃、高密度GPU机柜 80 ℃。
2. **超限判据**（4.1）：条文为「超过」，即**严格大于**才判需检修；**运行温度等于限值不算超限**。
3. **告警判据**（4.2）：24 小时内告警 **≥3 次**即判需检修，**与温度是否超限无关**，属独立触发条件。
4. **不适用**（4.3）：状态为「厂商保修返修中」的设备不纳入本次判定，直接判「不适用」；**该条优先**，不再套用 4.1 / 4.2。

## 二、逐台判定

### SV-401 ｜ 需检修
- **触发条款：4.1、4.2（两条同时触发）**
- 机柜 A-01（通用计算），**额定温度上限为空** → 按机柜级限值 **62 ℃** 执行。
- 运行温度 **64 ℃ ＞ 62 ℃**，超过限值 → 触发 4.1。
- 24h 告警 **4 次 ≥ 3 次** → 同时触发 4.2。
- 两条独立成立，任一即需检修。

### SV-402 ｜ 无需检修
- **触发条款：无**
- 机柜 A-01（通用计算），额定温度上限 **62 ℃**（有值，直接采用）。
- 运行温度 **62 ℃**，与限值**相等**，未「超过」→ 不触发 4.1。
- 24h 告警 0 次 ＜ 3 次 → 不触发 4.2。

### SV-403 ｜ 无需检修
- **触发条款：无**
- 机柜 A-02（高密度GPU），**额定温度上限为空** → 按机柜级限值 **80 ℃** 执行。
- 运行温度 **78 ℃ ＜ 80 ℃**，未超限 → 不触发 4.1。
- 24h 告警 0 次 → 不触发 4.2。

### SV-404 ｜ 不适用
- **触发条款：4.3**
- 状态为「厂商保修返修中」，按 4.3 不纳入本次判定。
- 说明：该设备运行温度 82 ℃、额定值空缺（机柜 B-01 为高密度GPU，限值 80 ℃），单看温度已超限；但 4.3 优先，本设备已返厂保修，**不在本次报修范围内**，故判「不适用」而非「需检修」。

### SV-405 ｜ 无需检修
- **触发条款：无**
- 机柜 B-02（通用计算），额定温度上限 **75 ℃**（**有值**）。
- 按 4.1，**有额定值时以额定值为准，不套用机柜级限值**，故限值取 **75 ℃**（而非通用计算机柜的 62 ℃）。
- 运行温度 **75 ℃**，与限值**相等**，未「超过」→ 不触发 4.1。
- 24h 告警 0 次 → 不触发 4.2。
- ⚠️ 见第三节「需确认事项」。

### SV-406 ｜ 无需检修（存疑，见下）
- **触发条款：无**
- 机柜 C-01（**存储专用**），**额定温度上限为空**。
- 规范 4.1 的机柜级限值只列了「通用计算机柜 62 ℃」「高密度GPU机柜 80 ℃」，**未给出「存储专用」机柜的限值**。
- 运行温度 **50 ℃**，为本次全部设备中最低，**低于规范已列机柜级限值的下限 62 ℃**，无论按哪一档现有参考值判断均不超限 → 判「无需检修」。
- 24h 告警 0 次 → 不触发 4.2。
- ⚠️ 见第三节「需确认事项」。

### SV-407 ｜ 需检修
- **触发条款：4.1**
- 机柜 C-02（高密度GPU），额定温度上限 **80 ℃**（有值，直接采用）。
- 运行温度 **88 ℃ ＞ 80 ℃**，超过限值 → 触发 4.1。
- 24h 告警 1 次 ＜ 3 次 → **不**触发 4.2（本台仅由温度触发）。

## 三、需确认事项（报修前建议核实）

1. **SV-406 缺「存储专用」机柜级限值**：规范 v3.2 第 4.1 条只定义了通用计算机柜与高密度GPU机柜两档机柜级限值，C-01「存储专用」机柜无对应限值，而该设备额定温度上限又为空。本次因实测 50 ℃ 远低于现有任一档限值，判「无需检修」结论稳健；但**建议在规范中补充存储机柜的限值条款**，或确认 C-01 是否应归入某一档，以免后续出现临界温度时无法判定。
2. **SV-405 额定值高于机柜级限值**：该设备属通用计算（机柜级限值 62 ℃），但表内额定温度上限为 75 ℃。按 4.1 原文「额定值优先」，本次取 75 ℃，故 75 ℃ 未超限、判「无需检修」。若机柜级限值的本意是**不可被设备额定值放宽的硬上限**，则本台应判「需检修」。**两种口径结论相反，建议明确 4.1 中额定值与机柜级限值的优先级关系后再定稿。**
