# 检修判定说明

依据：《机房设备维护规范 v3.2》第 4 章停机检修判据
数据来源：`巡检数据.csv`（2026-09 巡检）
判定表：`检修判定表.csv`

## 判据回顾

- **4.1** 运行温度 > 额定温度上限 → 需检修。额定温度上限列为空的设备，按其机柜级限值执行：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。
- **4.2** 24 小时内告警 ≥3 次 → 需检修（无论温度是否超限）。
- **4.3** 状态为「厂商保修返修中」的设备不纳入本次判定 → 不适用。

## 逐台判定

### SV-401 — 需检修
- 额定温度上限列为空，机柜用途为「通用计算」，按 4.1 取机柜级限值 **62 ℃**。
- 运行温度 **64 ℃＞62 ℃**，触发 **4.1**。
- 24h 告警 **4 次 ≥3 次**，同时触发 **4.2**。
- 两条判据均成立，故判需检修。

### SV-402 — 无需检修
- 额定温度上限 **62 ℃**，运行温度 **62 ℃**，等于限值而非超过，未触发 4.1。
- 24h 告警 **0 次**，未触发 4.2。
- 无判据成立，故判无需检修。

### SV-403 — 无需检修
- 额定温度上限列为空，机柜用途为「高密度 GPU」，按 4.1 取机柜级限值 **80 ℃**。
- 运行温度 **78 ℃＜80 ℃**，未触发 4.1。
- 24h 告警 **0 次**，未触发 4.2。
- 故判无需检修。

### SV-404 — 不适用
- 状态为「厂商保修返修中」，按 **4.3** 不纳入本次判定。
- 备注：该机运行温度 82 ℃、额定上限为空，若按高密度 GPU 机柜限值 80 ℃ 衡量本会超限，但依 4.3 直接判为不适用，不列入本次报修。

### SV-405 — 无需检修
- 额定温度上限 **75 ℃**，运行温度 **75 ℃**，等于限值而非超过，未触发 4.1。
- 24h 告警 **0 次**，未触发 4.2。
- 故判无需检修。

### SV-406 — 无需检修（限值缺失，需复核）
- 额定温度上限列为空，机柜用途为「**存储专用**」。
- 但规范 4.1 只定义了「通用计算机柜 62 ℃」和「高密度 GPU 机柜 80 ℃」两类机柜级限值，**没有「存储专用」机柜的限值**，因此 4.1 对这台设备缺少可直接套用的限值。
- 24h 告警 **0 次＜3 次**，未触发 4.2。
- 综合：无任一条判据成立，从保守角度（即便按规范中最严的 62 ℃ 衡量，运行温度 50 ℃ 也远未超限）判为**无需检修**。
- ⚠️ **待确认**：规范缺少「存储专用」机柜级限值，此处判定为按现有条款无触发项的默认结论，建议请规范维护人补充该类机柜限值后复核。

### SV-407 — 需检修
- 额定温度上限 **80 ℃**，运行温度 **88 ℃>80 ℃**，触发 **4.1**。
- 24h 告警 **1 次＜3 次**，未触发 4.2。
- 故判需检修。
