# 机房设备检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- 数据：`巡检数据.csv`（本轮巡检）
- 结果表：`检修判定表.csv`
- 判定口径：
  - **4.1** 运行温度超过额定温度上限 → 需检修。额定上限以巡检数据表该行为准；**该列为空时，按机柜级限值**（通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃）。「超过」为严格大于，**等于上限不算超限**。
  - **4.2** 24 小时内告警 ≥3 次 → 需检修（不论温度）。
  - **4.3** 状态为「厂商保修返修中」→ 不纳入本次判定，判「不适用」。

---

## SV-401 — 需检修（条款 4.1）

- 机柜 A-01 / 通用计算；**额定温度上限为空** → 按通用计算机柜机柜级限值 **62 ℃**。
- 运行温度 **64 ℃ > 62 ℃**，超限。
- 24h 告警 4 次，虽也 ≥3 次可触发 4.2，但温度已先触发 4.1，故触发条款记为 4.1。

## SV-402 — 无需检修（无触发条款）

- 额定温度上限 62 ℃（本行明确给出），运行温度 **62 ℃**。
- 62 **未超过** 62（等于上限，属临界但未超限），4.1 不触发。
- 24h 告警 0 次 < 3 次，4.2 不触发。
- ⚠️ 长期贴着上限运行，建议列入观察，但按现行判据不判需检修。

## SV-403 — 无需检修（无触发条款）

- 机柜 A-02 / 高密度 GPU；**额定温度上限为空** → 按高密度 GPU 机柜机柜级限值 **80 ℃**。
- 运行温度 **78 ℃ ≤ 80 ℃**，未超限。
- 24h 告警 0 次 < 3 次。

## SV-404 — 不适用（条款 4.3）

- 状态为「厂商保修返修中」，依 **4.3 不纳入本次判定**，判「不适用」。
- 说明：该机运行温度 82 ℃，若参与判定本会超过高密度 GPU 机柜限值 80 ℃（条款 4.1），但 4.3 已将其排除，故不判需检修，也不计入本轮报修。
- 待其保修返修返回后需重新巡检并纳入判定。

## SV-405 — 无需检修（无触发条款）

- 机柜 B-02 / 通用计算，但本行**额定温度上限明确给出 75 ℃**。
- 按 4.1 正文，额定上限**以数据表该行为准**，机柜级限值仅在**该列为空**时适用；因此此处用 75 ℃，**不适用**通用计算机柜默认的 62 ℃。
- 运行温度 **75 ℃ 未超过 75 ℃**（等于上限，未超限），4.1 不触发。
- 24h 告警 0 次 < 3 次。
- ⚠️ 同 SV-402，属临界工况，建议观察。

## SV-406 — 不适用（条款 4.1，限值缺失，无法判定）⚠️ **需确认**

- 机柜 C-01 / **存储专用**；**额定温度上限为空**。
- 按 4.1，该列为空时应按机柜级限值执行；但规范给出的机柜级限值**只有两档**——通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃，**未规定「存储专用」机柜的限值**。
- 因此本机**既无本行额定上限，也无适用的机柜级限值**，4.1 **无判据可用**；4.2（告警 0 次）、4.3（状态在用）均不触发。
- **这不是 4.3 意义上的「不纳入判定」，而是规范/数据缺口导致无法判定。** 表中暂以「不适用」占位，**报修前请确认**：需补规范中存储专用机柜的限值，或由设备侧提供该机额定温度上限，再行判定。
- 参考信息（非判据）：该机运行温度 50 ℃，即使按最严的 62 ℃ 也远未超限；但在此仅作参考，不作为判定依据。

## SV-407 — 需检修（条款 4.1）

- 机柜 C-02 / 高密度 GPU，额定温度上限 80 ℃（本行给出）。
- 运行温度 **88 ℃ > 80 ℃**，超限。
- 24h 告警 1 次 < 3 次，4.2 未触发；触发条款为 4.1。
