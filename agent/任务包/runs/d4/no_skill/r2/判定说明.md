# 检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- 数据来源：`巡检数据.csv`（本月巡检数据）
- 判定表：`检修判定表.csv`（已填）
- 判定日期：2026-09-29

## 一、判定规则回顾

| 条款 | 规则 |
| --- | --- |
| 4.1 | 运行温度**超过**额定温度上限的，判为需检修。该列为空的，按其机柜级限值执行：通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃。 |
| 4.2 | 24 小时内告警 **≥3 次**的，无论温度是否超限，均判为需检修。 |
| 4.3 | 状态为「厂商保修返修中」的设备不纳入本次判定，判为「不适用」。 |

两处口径说明：

1. **「超过」按严格大于理解**，运行温度**等于**额定上限不算超限，不触发 4.1。
2. **4.3 优先于 4.1／4.2**：状态为「厂商保修返修中」的设备直接判「不适用」，不再看温度和告警。

## 二、逐台判定

### SV-401 —— 需检修（触发 4.1、4.2）
- 机柜 A-01 为通用计算，额定温度上限列为空 → 取机柜级限值 **62 ℃**。
- 运行温度 **64 ℃ ＞ 62 ℃** → 触发 4.1。
- 24h 告警 **4 次 ≥ 3 次** → 同时触发 4.2。
- 两项条款独立成立，故条款号填 4.1、4.2。

### SV-402 —— 无需检修
- 额定温度上限 **62 ℃**，运行温度 **62 ℃**。
- 62 未超过 62（相等不作超限），不触发 4.1。
- 24h 告警 0 次 ＜ 3 次，不触发 4.2；状态为在用，不适用 4.3。
- **结论：无需检修。**

### SV-403 —— 无需检修
- 机柜 A-02 为高密度 GPU，额定温度上限列为空 → 取机柜级限值 **80 ℃**。
- 运行温度 **78 ℃ ≤ 80 ℃**，未超限，不触发 4.1。
- 24h 告警 0 次 ＜ 3 次，不触发 4.2。
- **结论：无需检修。**

### SV-404 —— 不适用（触发 4.3）
- 状态为「厂商保修返修中」→ 按 4.3 不纳入本次判定。
- 说明：该台运行温度 82 ℃，若按高密度 GPU 机柜限值 80 ℃ 本会超限，但 4.3 明确将其排除在本次判定之外，故仍判「不适用」，不做需检修处理。待返修回装后另行巡检判定。

### SV-405 —— 无需检修
- 额定温度上限 **75 ℃**，运行温度 **75 ℃**。
- 75 未超过 75（相等不作超限），不触发 4.1。
- 24h 告警 0 次 ＜ 3 次，不触发 4.2。
- **结论：无需检修。**

### SV-406 —— 无需检修（含规范缺口，见第三节）
- 机柜 C-01 用途为「**存储专用**」，额定温度上限列为空。
- 规范 4.1 只给出**通用计算机柜 62 ℃**和**高密度 GPU 机柜 80 ℃**两档机柜级限值，**未覆盖「存储专用」机柜**，因此该台没有可直接套用的机柜级限值。
- 在无对应限值的情况下，不能擅自套用其他用途机柜的限值。但就本台现状而言：运行温度 **50 ℃**，低于规范所列的**任一**限值（62 ℃／80 ℃），无论缺口如何填补都不构成温度超限；24h 告警 0 次 ＜ 3 次；状态为在用。
- 三个条款均不成立，故暂判 **无需检修**，并同时提请补充规范（见下）。

### SV-407 —— 需检修（触发 4.1）
- 额定温度上限 **80 ℃**，运行温度 **88 ℃**。
- 88 ℃ ＞ 80 ℃ → 触发 4.1。
- 24h 告警 1 次 ＜ 3 次，不触发 4.2。
- **结论：需检修。**

## 三、需提请确认的问题

**规范缺口：存储专用机柜缺机柜级温度限值。**

规范 4.1 规定额定温度上限列为空时按机柜级限值执行，但只列了通用计算（62 ℃）与高密度 GPU（80 ℃）两类。本月 SV-406（C-01，存储专用）正好命中该缺口。

- 本次处理：因 50 ℃ 低于任一已列限值，结论不受影响，暂判「无需检修」。
- 风险提示：一旦后续存储专用机柜出现 62～80 ℃ 之间的运行温度，将无法按现行规范判定。**建议在报修前推动规范补充存储专用机柜的机柜级限值**，否则该类设备存在判定盲区。

另需注意：SV-404 因「厂商保修返修中」判为不适用，其运行温度 82 ℃ 已高于高密度 GPU 机柜限值 80 ℃。该台不进入本月报修清单，但返修回装后应单独安排复检。
