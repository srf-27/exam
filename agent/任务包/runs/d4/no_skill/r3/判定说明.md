# 机房设备检修判定说明

- 判定依据：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
- 数据来源：`巡检数据.csv`（本月巡检）
- 判定结果：`检修判定表.csv`
- 判定规则摘要
  - **4.1**：运行温度**超过**额定温度上限 → 需检修。上限取本行「额定温度上限」列；**该列为空时**，按机柜级限值执行（通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃）。
  - **4.2**：24 小时内告警 **≥3 次** → 需检修（不论温度是否超限）。
  - **4.3**：状态为「厂商保修返修中」→ 不适用（不纳入本次判定）。
  - 「超过」按严格大于理解，**等于上限不算超限**。

---

## SV-401 → 需检修

- 数据：A-01 通用计算柜，额定上限**空**，运行温度 64 ℃，24h 告警 4 次，在用。
- 上限取值：本行额定上限为空，按 4.1 转用机柜级限值 —— A-01 为通用计算机柜，限值 **62 ℃**。
- 温度判定（4.1）：64 ℃ **＞** 62 ℃，超限，触发。
- 告警判定（4.2）：4 次 **≥** 3 次，触发。
- 结论：**需检修**，两条条款同时触发（触发条款列记为 `4.1、4.2`）。这台的温度仅超限 2 ℃，容易被漏看，但告警次数已单独构成检修条件。

## SV-402 → 无需检修

- 数据：A-01 通用计算柜，额定上限 62 ℃，运行温度 62 ℃，24h 告警 0 次，在用。
- 上限取值：本行已填 62 ℃，直接采用（与机柜级限值恰好相同）。
- 温度判定（4.1）：62 ℃ **等于** 62 ℃，规范用词为「超过」，未超过，不触发。
- 告警判定（4.2）：0 次 ＜ 3 次，不触发。
- 结论：**无需检修**。这台是温度贴上限的边界设备，建议继续观察，本次不构成检修条件。

## SV-403 → 无需检修

- 数据：A-02 高密度 GPU 柜，额定上限**空**，运行温度 78 ℃，24h 告警 0 次，在用。
- 上限取值：本行额定上限为空，转用机柜级限值 —— A-02 为高密度 GPU 机柜，限值 **80 ℃**。
- 温度判定（4.1）：78 ℃ ＜ 80 ℃，未超限，不触发。78 ℃ 若误按通用柜 62 ℃ 判会误判为需检修，此处必须按 GPU 柜限值。
- 告警判定（4.2）：0 次 ＜ 3 次，不触发。
- 结论：**无需检修**。注意 GPU 柜温度普遍偏高，应始终对照 80 ℃ 而非 62 ℃。

## SV-404 → 不适用

- 数据：B-01 高密度 GPU 柜，额定上限**空**，运行温度 82 ℃，24h 告警 0 次，**状态为「厂商保修返修中」**。
- 判定（4.3）：状态为厂商保修返修中，不纳入本次判定。
- 结论：**不适用**。单独说明：该机运行温度 82 ℃ 已高于其机柜级限值 80 ℃，**若在修设备**（即未处于返修状态）本应判为需检修。本次依 4.3 排除，但该机返修完成后应重新核查温度，不能因本次「不适用」而漏掉后续处理。

## SV-405 → 无需检修

- 数据：B-02 通用计算柜，额定上限 **75 ℃**，运行温度 75 ℃，24h 告警 0 次，在用。
- 上限取值：本行额定上限**已填 75 ℃**，按 4.1「该列为空时才按机柜级限值执行」，此处**采用本行 75 ℃，不采用通用柜 62 ℃**。
- 温度判定（4.1）：75 ℃ **等于** 75 ℃，未超过，不触发。若误用机柜级限值 62 ℃，会把 75 ℃ 判成超限 13 ℃，属误判。
- 告警判定（4.2）：0 次 ＜ 3 次，不触发。
- 结论：**无需检修**。

## SV-406 → 无需检修（存疑，建议上报确认）

- 数据：C-01 **存储专用**柜，额定上限**空**，运行温度 50 ℃，24h 告警 0 次，在用。
- 上限取值：本行额定上限为空，按 4.1 应转用机柜级限值；但**规范 4.1 只给出了「通用计算机柜 62 ℃」和「高密度 GPU 机柜 80 ℃」两档，未规定「存储专用机柜」的限值**，该机柜类型在限值表中缺项。
- 温度判定（4.1）：无适用限值，严格讲无法直接对照。参考判断：运行温度 50 ℃ **低于现行两档限值中较低的 62 ℃**，无论存储柜限值定为何值（通常不高于通用柜），50 ℃ 都不构成超限。
- 告警判定（4.2）：0 次 ＜ 3 次，不触发。
- 结论：**无需检修**，但**此判定含推断成分**——依据是「50 ℃ 低于已知的最低限值 62 ℃」，而非规范中的明文限值。已在判定表「触发条款」列标注「无（存疑）」。
- **建议**：向设备科/规范归口部门确认存储专用机柜的机柜级限值，并在规范 4.1 中补入该档；本次温度余量很大（50 ℃），实际检修风险低，但规范缺项应补齐。

## SV-407 → 需检修

- 数据：C-02 高密度 GPU 柜，额定上限 80 ℃，运行温度 88 ℃，24h 告警 1 次，在用。
- 上限取值：本行已填 80 ℃，直接采用。
- 温度判定（4.1）：88 ℃ **＞** 80 ℃，超限 8 ℃，触发。
- 告警判定（4.2）：1 次 ＜ 3 次，不触发（本条不构成，但 4.1 已触发）。
- 结论：**需检修**。本台为本次唯一「明确超限」的设备，超限幅度最大，报修时应优先安排。
