# 机房设备巡检判定说明

判定依据：《机房设备维护规范 v3.2》第 4 章「停机检修判据」；数据来源：`巡检数据.csv`（巡检周期见原始记录）。
输出表：`检修判定表.csv`。判定值仅取三个枚举之一：**需检修 / 无需检修 / 不适用**。

## 一、判定规则与顺序

| 条款 | 条件 | 结论 |
|---|---|---|
| 4.1 | 运行温度 **严格超过** 额定温度上限 | 需检修 |
| 4.1 回退 | 额定温度上限为空时，改用**机柜级限值** | — |
| 4.2 | 24h 告警 **≥3 次**（无论温度是否超限） | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定 → **不适用** |

机柜级限值（规范 4.1 原文）：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。

两条顺序约定：

1. **温度用严格大于**：「超过」不含等于，等于限值不算超标（SV-402、SV-405 即此边界）。
2. **4.3 优先于 4.1/4.2**：4.3 的措辞是「不纳入本次判定」，属范围排除，先于温度、告警判据生效；4.2 的「无论温度是否超限」仅表明告警判据优先于温度判据，不改变 4.3 的排除效力。

## 二、逐台判定

### SV-401 → 需检修（触发 4.1、4.2）
- 机柜 A-01，用途「通用计算」，额定温度上限为空 → 走 4.1 回退，取通用计算机柜限值 **62 ℃**。
- 运行温度 **64 ℃ > 62 ℃** → 触发 4.1。
- 24h 告警 **4 次 ≥ 3 次** → 同时触发 4.2。两条均指向需检修。

### SV-402 → 无需检修（未触发）
- 额定温度上限 62 ℃（记录值），运行温度 **62 ℃**，等于限值，不满足「超过」。
- 24h 告警 0 次 < 3 次。无条款触发。

### SV-403 → 无需检修（未触发）
- 机柜 A-02，用途「高密度 GPU」，额定温度上限为空 → 走 4.1 回退，取高密度 GPU 机柜限值 **80 ℃**。
- 运行温度 **78 ℃ < 80 ℃**，未超标。
- 24h 告警 0 次 < 3 次。无条款触发。

### SV-404 → 不适用（触发 4.3）
- 状态为「厂商保修返修中」→ 按 4.3 不纳入本次判定，判为**不适用**。
- 说明其温度：运行温度 82 ℃ > 80 ℃（GPU 回退限值），本可触及 4.1；但 4.3 是范围排除，优先于 4.1，故不作检修判定，也不填 4.1。

### SV-405 → 无需检修（未触发）
- 额定温度上限 **75 ℃**（记录值，不回退），运行温度 **75 ℃**，等于限值，不满足「超过」。
- 24h 告警 0 次 < 3 次。无条款触发。

### SV-406 → 无需检修（未触发）⚠️ 存在规范缺口
- 机柜 C-01，用途「**存储专用**」，额定温度上限为空 → 需按 4.1 回退取机柜级限值。
- **但规范 v3.2 的机柜级限值只定义了「通用计算机柜 62 ℃」和「高密度 GPU 机柜 80 ℃」两类，未定义存储专用机柜的限值。** 该设备的限值因此无规范来源。
- 在此情况下，运行温度 **50 ℃** 低于全部已定义限值（62/80），也拿不出任何可依据的「超过限值」结论，故不能判 4.1「需检修」。
- 其状态为「在用」，不符合 4.3 的「厂商保修返修中」，故也不能判「不适用」。
- 综合：无条款触发，判**无需检修**。
- **报修提示**：此行为按现有规范能下的最稳妥结论，但根因是存储机柜限值缺定义。建议向规范维护方确认存储专用机柜的限值条款后再复核本行；若日后补入限值且 50 ℃ 超过该值，本行应改判。

### SV-407 → 需检修（触发 4.1）
- 额定温度上限 **80 ℃**（记录值），运行温度 **88 ℃ > 80 ℃** → 触发 4.1。
- 24h 告警 1 次 < 3 次，未触发 4.2。

## 三、汇总

| 设备编号 | 判定 | 触发条款 | 关键数值 |
|---|---|---|---|
| SV-401 | 需检修 | 4.1、4.2 | 64 ℃ > 62 ℃（回退通用限值）；告警 4 次 |
| SV-402 | 无需检修 | 无 | 62 ℃ = 62 ℃；告警 0 次 |
| SV-403 | 无需检修 | 无 | 78 ℃ < 80 ℃（回退 GPU 限值）；告警 0 次 |
| SV-404 | 不适用 | 4.3 | 状态「厂商保修返修中」，优先于温度 82 ℃ > 80 ℃ |
| SV-405 | 无需检修 | 无 | 75 ℃ = 75 ℃；告警 0 次 |
| SV-406 | 无需检修 | 无 | 50 ℃，存储机柜限值未定义（规范缺口）；告警 0 次 |
| SV-407 | 需检修 | 4.1 | 88 ℃ > 80 ℃；告警 1 次 |

其中：
- 触发 4.1 的：SV-401、SV-407（SV-401 同时触发 4.2）。
- 触发 4.3 的：SV-404。
- 走 4.1 回退（额定温度上限为空）的：SV-401、SV-403、SV-406；其中 SV-406 因限值本身未定义而无法完成回退。
- 需报修设备：**SV-401、SV-407**。
