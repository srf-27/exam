# 机房设备检修判定说明

- 判定依据：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- 数据来源：`巡检数据.csv`（本说明与 `检修判定表.csv` 均未改动规范和数据，仅读取）
- 结论取值：需检修 / 无需检修 / 不适用

## 一、判定所用的条款

| 条款 | 内容 | 说明 |
| --- | --- | --- |
| 4.1 | 运行温度**超过**额定温度上限 → 需检修 | 「超过」为严格大于；上限列为空时，回退到机柜级限值 |
| 4.1 回退 | 额定温度上限为空 → 按机柜级限值执行 | 通用计算机柜 62℃；高密度 GPU 机柜 80℃ |
| 4.2 | 24 小时内告警 **≥3 次** → 需检修 | 无论温度是否超限 |
| 4.3 | 状态为「厂商保修返修中」→ 不纳入本次判定 | 判「不适用」，优先级最高（先排除） |

判定顺序：**4.3（先排除）→ 4.2 → 4.1**。4.1 与 4.2 都指向「需检修」，不冲突；真正影响结论先后的是 4.3 的排除优先。

## 二、逐台判定

### SV-401 —— 需检修（触发 4.1、4.2）
- 额定温度上限为空 → 按其机柜用途「通用计算」取机柜级限值 **62℃**。
- 运行温度 **64℃ > 62℃**，触发 **4.1**。
- 24h 告警 **4 次 ≥ 3 次**，另触发 **4.2**（无论温度是否超限）。
- 两条独立依据同时成立，结论：需检修。

### SV-402 —— 无需检修（未触发）
- 额定温度上限为记录值 **62℃**（该列非空，正常采用）。
- 运行温度 **62℃**，未超过 62℃（「超过」是严格大于），**4.1 不触发**。
- 24h 告警 0 次 < 3 次，**4.2 不触发**。
- 结论：无需检修。此台为典型的「贴线」情形，不因等于阈值而升级。

### SV-403 —— 无需检修（未触发）
- 额定温度上限为空 → 按机柜用途「高密度GPU」取机柜级限值 **80℃**。
- 运行温度 **78℃ ≤ 80℃**，**4.1 不触发**。
- 告警 0 次 < 3 次，**4.2 不触发**。
- 结论：无需检修。

### SV-404 —— 不适用（触发 4.3）
- 状态为「厂商保修返修中」，按 **4.3 不纳入本次判定**，直接判「不适用」。
- 补充说明：其运行温度 82℃ 若按 4.1 本已超过高密度 GPU 机柜限值 80℃，但 4.3 属于排除性条款，优先于 4.1 适用，故不因温度超限改判需检修。
- 结论：不适用。

### SV-405 —— 无需检修（未触发）
- 额定温度上限为**记录值 75℃**，该列非空，**直接采用记录值**，不再套用通用计算机柜的 62℃。
- 运行温度 **75℃**，未超过 75℃，**4.1 不触发**。
- 告警 0 次 < 3 次，**4.2 不触发**。
- 结论：无需检修。此台最易误判：若错用机柜限值 62℃ 会得出「需检修」，但回退规则（取机柜限值）仅在该列为空时适用。

### SV-406 —— 无需检修（未触发）
- 额定温度上限为空，本应回退机柜级限值；但规范仅列出「通用计算机柜 62℃」「高密度 GPU 机柜 80℃」，**未给出「存储专用」机柜的限值**。
- 现有可查的两个机柜级限值分别为 62℃ 与 80℃；运行温度 **50℃** 低于其中任一个，故在任何已列限值下均不满足 4.1 的「超过」条件，**4.1 不触发**。
- 告警 0 次 < 3 次，**4.2 不触发**。
- 结论：无需检修。建议：规范后续版本应补齐「存储专用机柜」的机柜级限值，以便该列缺值时判定依据更完备。

### SV-407 —— 需检修（触发 4.1）
- 额定温度上限为记录值 **80℃**。
- 运行温度 **88℃ > 80℃**，触发 **4.1**。
- 告警 1 次 < 3 次，**4.2 不触发**（但 4.1 已足以判需检修）。
- 结论：需检修。

## 三、汇总与提醒

| 设备编号 | 判定 | 触发条款 | 关键数值 |
| --- | --- | --- | --- |
| SV-401 | 需检修 | 4.1、4.2 | 64℃ > 62℃（机柜回退）；告警 4 次 |
| SV-402 | 无需检修 | 无 | 62℃ 未超过 62℃ |
| SV-403 | 无需检修 | 无 | 78℃ ≤ 80℃（机柜回退） |
| SV-404 | 不适用 | 4.3 | 厂商保修返修中（优先排除） |
| SV-405 | 无需检修 | 无 | 75℃ 未超过 75℃（用记录值） |
| SV-406 | 无需检修 | 无 | 50℃ 低于已列机柜限值；存储专用限值规范未列 |
| SV-407 | 需检修 | 4.1 | 88℃ > 80℃ |

本次共 7 台：需检修 2 台（SV-401、SV-407），无需检修 4 台（SV-402、SV-403、SV-405、SV-406），不适用 1 台（SV-404）。报修清单以上述「需检修」两台为准。
