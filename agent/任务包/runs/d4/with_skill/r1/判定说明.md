# 检修判定说明

- 判定依据规范：《机房设备维护规范 v3.2》第 4 章「停机检修判据」
- 数据来源：`巡检数据.csv`（未作任何改动）
- 判定值域：需检修 / 无需检修 / 不适用

## 一、判定规则与顺序

规范中可用的硬约束共 3 条：

| 条款 | 触发条件 | 结论 |
| --- | --- | --- |
| 4.1 | 运行温度 **超过** 额定温度上限；该列为空时按机柜级限值（通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃） | 需检修 |
| 4.2 | 24 小时内告警 **≥3 次**（无论温度是否超限） | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不适用 |

判定顺序（先排除、后触发）：

1. **先看 4.3**：凡是「厂商保修返修中」的设备，不纳入本次判定，直接判「不适用」，不再看温度与告警。
2. **再看 4.1 与 4.2**：二者分别独立触发「需检修」，命中任一即为需检修；同时命中则两条都列。
3. **均未命中**：判「无需检修」。

两点口径说明：

- 「超过」按**严格大于**理解，运行温度等于上限不算超限（SV-402、SV-405 即此类边界）。
- 额定温度上限为空时，才回退到机柜级限值；该列有值时以表列值为准（SV-405 用 75 ℃，不套用通用计算机柜的 62 ℃）。

## 二、逐台判定

### SV-401 — 需检修（触发 4.1、4.2）
- 额定温度上限列为空 → 按机柜级限值。机柜 A-01 用途为「通用计算」，取通用计算机柜限值 **62 ℃**（回退推算值）。
- 运行温度 **64 ℃ ＞ 62 ℃**，超过上限，触发 4.1。
- 24h 告警 **4 次 ≥ 3 次**，触发 4.2。
- 两条均命中，结论一致为需检修。

### SV-402 — 无需检修（无触发条款）
- 额定温度上限 **62 ℃**（表列值）。
- 运行温度 **62 ℃**，等于上限、未超过，不满足 4.1。
- 24h 告警 0 次 < 3 次，不满足 4.2。
- 无条款触发。

### SV-403 — 无需检修（无触发条款）
- 额定温度上限列为空 → 按机柜级限值。机柜 A-02 用途为「高密度 GPU」，取高密度 GPU 机柜限值 **80 ℃**（回退推算值）。
- 运行温度 **78 ℃ ＜ 80 ℃**，未超过，不满足 4.1。
- 24h 告警 0 次 < 3 次，不满足 4.2。
- 无条款触发。

### SV-404 — 不适用（触发 4.3）
- 状态为「**厂商保修返修中**」，按 4.3 不纳入本次判定，判「不适用」。
- 补充说明：该机柜为高密度 GPU，机柜级限值 80 ℃，运行温度 82 ℃ 本会触发 4.1；但 4.3 属排除性条款，优先级最高，故最终判不适用。

### SV-405 — 无需检修（无触发条款）
- 额定温度上限 **75 ℃**（表列值）。该列有值，不适用机柜级回退。
- 运行温度 **75 ℃**，等于上限、未超过，不满足 4.1。
- 24h 告警 0 次 < 3 次，不满足 4.2。
- 无条款触发。

### SV-406 — 无需检修（无触发条款）
- 额定温度上限列为空 → 需按机柜级限值回退，但机柜 C-01 用途为「**存储专用**」，规范仅规定了通用计算机柜（62 ℃）与高密度 GPU 机柜（80 ℃）两档，**未给出存储专用机柜的限值**。
- 无适用上限可比，即不构成「超过额定温度上限」，4.1 无法成立；运行温度 50 ℃ 亦处于低位。
- 24h 告警 0 次 < 3 次，不满足 4.2。
- 无条款触发，按值域取「无需检修」。

> ⚠️ **提请注意**：本条是本次判定中唯一的规则缺口。规范未覆盖「存储专用机柜 + 额定温度上限为空」的组合，现有结论（无需检修）建立在「无适用上限即不构成超限」这一默认之上。该机运行温度 50 ℃、无告警，实际风险很低；但若报修时存储专用机柜需要明确限值口径，建议向规范归口部门确认后补入限值。按现有规范，其余三值中「需检修」与「不适用」均无依据，故不能改判。

### SV-407 — 需检修（触发 4.1）
- 额定温度上限 **80 ℃**（表列值）。
- 运行温度 **88 ℃ ＞ 80 ℃**，超过上限，触发 4.1。
- 24h 告警 1 次 < 3 次，未触发 4.2。
- 仅 4.1 命中。
