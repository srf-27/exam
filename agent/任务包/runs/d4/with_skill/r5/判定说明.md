# 机房设备巡检判定说明

- **判定依据**：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- **数据来源**：`巡检数据.csv`（本次共 7 台设备，逐台一行）
- **判定值域**：需检修 / 无需检修 / 不适用
- **填表去向**：`检修判定表.csv`（现成表格，就地填写）

## 一、判定所用的规则

| 条款 | 条件 | 结论 |
| --- | --- | --- |
| 4.1 | 运行温度 **超过** 额定温度上限 | 需检修 |
| 4.2 | 24h 告警 **≥3 次**（无论温度是否超限） | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定，判「不适用」 |

两条附带规则：

1. **回退规则（4.1 内）**：额定温度上限列为空时，按**机柜级限值**执行——通用计算机柜 62℃，高密度GPU机柜 80℃。
2. **优先级**：4.3 是「不纳入本次判定」，优先于温度与告警判据；4.1 与 4.2 可同时成立，结论同为需检修。

关键理解：规范原文用「**超过**」，是**严格大于**，等于限值不算超限。以下 SV-402、SV-405 两台正好压在限值上，均据此判为无需检修。

## 二、逐台判定

### SV-401 — 需检修（触发 4.1、4.2）
- 额定温度上限为空 → 按机柜级限值执行：机柜 A-01 用途为通用计算，限值 **62℃**。
- 运行温度 **64℃ ＞ 62℃** → 触发 4.1。
- 24h 告警 **4 次 ≥ 3** → 同时触发 4.2。
- 两条判据同向成立，结论需检修。

### SV-402 — 无需检修（无触发）
- 额定温度上限为记录值 **62℃**，非空，不启用回退规则。
- 运行温度 **62℃，未超过 62℃**（等于限值，不算「超过」）→ 不触发 4.1。
- 24h 告警 0 次＜3 → 不触发 4.2。

### SV-403 — 无需检修（无触发）
- 额定温度上限为空 → 按机柜级限值执行：机柜 A-02 用途为高密度GPU，限值 **80℃**。
- 运行温度 **78℃，未超过 80℃** → 不触发 4.1。
- 24h 告警 0 次＜3 → 不触发 4.2。

### SV-404 — 不适用（触发 4.3）
- 状态为「**厂商保修返修中**」→ 依 4.3 不纳入本次判定，直接判「不适用」。
- 说明：本机机柜 B-01 为高密度GPU（限值 80℃），运行温度 **82℃ 本已超限、按 4.1 会判需检修**；但 4.3 的排除规则优先，故最终判「不适用」。这也是全表唯一出现判据冲突的一台。

### SV-405 — 无需检修（无触发）
- 额定温度上限为记录值 **75℃**，非空，不启用回退规则（注意：75℃ 并非常见机柜限值，此处以表内记录值为准）。
- 运行温度 **75℃，未超过 75℃**（等于限值，不算「超过」）→ 不触发 4.1。
- 24h 告警 0 次＜3 → 不触发 4.2。

### SV-406 — 无需检修（无触发）
- 额定温度上限为空 → 本应回退到机柜级限值，但机柜 C-01 用途为「**存储专用**」，规范 4.1 只给出了通用计算（62℃）与高密度GPU（80℃）两档，**未规定存储专用机柜的限值**。
- 数据侧影响：运行温度 **50℃ 同时低于上述两项已列限值**，无论按哪一档都不构成超限，因此缺限值不影响本机结论，判无需检修。
- 24h 告警 0 次＜3 → 不触发 4.2。
- **提请留意**：规范存在一处覆盖缺口——存储专用机柜无对应机柜级限值。本次因温度余量大（50℃）未受影响；若后续该机柜设备额定温度上限仍为空且温度接近限值，将无法据规范判定，建议补全规范中的此类限值或补齐设备额定温度上限。

### SV-407 — 需检修（触发 4.1）
- 额定温度上限为记录值 **80℃**，非空，不启用回退规则。
- 运行温度 **88℃ ＞ 80℃** → 触发 4.1。
- 24h 告警 **1 次＜3** → 不触发 4.2（本条仅由温度触发）。
