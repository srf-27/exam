# 机房设备停机检修判定说明

- 判定依据：《机房设备维护规范 v3.2》第 4 章「停机检修判据」（条款 4.1 / 4.2 / 4.3）
- 数据来源：`巡检数据.csv`（原始数据与规范均只读，未作改动）
- 判定结论取值域：**需检修 / 无需检修 / 不适用**

## 一、约束清单（第一轮挖出的硬约束）

| # | 类型 | 条款 | 内容 |
|---|---|---|---|
| 1 | 枚举与格式 | 任务要求 | `判定` 列只能取 需检修 / 无需检修 / 不适用 |
| 2 | 触发条件 | 4.1 | 运行温度 **超过** 额定温度上限的 → 需检修（「超过」为严格大于，等于不触发） |
| 3 | 回退与缺省 | 4.1 内嵌从句 | 额定温度上限列为空的设备 → **按其机柜级限值执行**；机柜级限值：通用计算机柜 62℃、高密度GPU机柜 80℃ |
| 4 | 触发条件 | 4.2 | 24 小时内告警 **≥3 次** → 无论温度是否超限，均判需检修 |
| 5 | 排除与优先 | 4.3 | 状态为「厂商保修返修中」的设备 → 不纳入本次判定，判「不适用」（优先于 4.1、4.2） |

### 判定顺序（第二轮）

工作区内未附带示例/样表，无法用示例反推顺序，故按规范文本自身的措辞定序：

1. **先 4.3 排除**——「不纳入本次判定」是适用范围条款，凡命中者直接出「不适用」，不再走温度/告警；
2. **再 4.2**——其自带「无论温度是否超限」，是跨温度的独立触发条件，与 4.1 并列命中时结论一致（均为需检修），不存在冲突；
3. **后 4.1**——温度比较，注意缺省列要走机柜级限值。

## 二、逐台判定

### SV-201 → 无需检修
- 额定温度上限列为空 → 回退：机柜 A-01 用途「通用计算」→ 机柜级限值 **62℃**。
- 运行温度 62℃，`62 > 62` 不成立，未超限。
- 告警 0 次 < 3 次，4.2 不触发。
- 判定：无需检修（依据条款 4.1 + 回退规则）。

### SV-202 → 需检修
- 额定温度上限列为空 → 回退：通用计算机柜限值 **62℃**。
- 运行温度 63℃ > 62℃，触发 4.1。
- 判定：需检修（条款 4.1）。

### SV-203 → 需检修
- 额定温度上限列为空 → 回退：机柜 A-02 用途「高密度GPU」→ 限值 **80℃**。
- 运行温度 80℃，`80 > 80` 不成立，**温度未超限**；告警 3 次 ≥ 3 次。
- 4.2 明确「无论温度是否超限」，故温度正常不影响结论，触发 4.2。
- 判定：需检修（条款 4.2）。

### SV-204 → 需检修
- 额定温度上限 90℃（该列有值，不走回退）。
- 运行温度 95℃ > 90℃，触发 4.1；同时告警 10 次 ≥ 3 次，触发 4.2。
- 两条并列命中，结论一致。
- 判定：需检修（条款 4.1；4.2）。

### SV-205 → 不适用
- 状态为「厂商保修返修中」，命中 4.3 排除条款，**不纳入本次判定**。
- 虽其运行温度 68℃ < 额定上限 70℃、告警 0 次，本可判「无需检修」，但 4.3 为适用范围条款、优先级最高，故出「不适用」而非「无需检修」。
- 判定：不适用（条款 4.3）。该行为本次报修应剔除项。

### SV-206 → 无需检修
- 额定温度上限 88℃，运行温度 88℃，`88 > 88` 不成立，未超限。
- 告警 0 次 < 3 次，4.2 不触发。
- 判定：无需检修（条款 4.1）。

### SV-207 → 无需检修
- 额定温度上限 72℃，运行温度 71℃，未超限（4.1 不触发）。
- 告警 2 次 < 3 次，4.2 不触发。
- 判定：无需检修（条款 4.1；4.2）。

### SV-208 → 无需检修（附说明，见下）
- 额定温度上限列为空 → 本应回退到机柜级限值；但该设备机柜 D-01 用途为「**存储专用**」，而 4.1 给出的机柜级限值只覆盖「通用计算机柜 62℃」「高密度GPU机柜 80℃」两类，**未覆盖存储专用机柜**。
- 因此 4.1 对该行没有可适用的限值，无法构成触发条件；4.2 方面告警 0 次 < 3 次，不触发。
- 运行温度 55℃ 亦低于现有两类限值中的最低值 62℃。
- 判定：无需检修（条款 4.1；4.2）。

## 三、需要提醒的两点

1. **SV-208 属规范空白，建议报修前确认。** 规范 v3.2 的机柜级限值表未包含「存储专用」机柜。本行因告警为 0、温度仅 55℃，按现有条款判「无需检修」是安全的；但若后续出现存储专用机柜温度偏高而无额定上限的行，现有规范将无法判定。建议向规范维护方确认是否补充存储机柜限值。
2. **严格大于/等于的边界。** SV-201（62℃/限值62℃）、SV-203（80℃/限值80℃）、SV-206（88℃/限值88℃）三处均为「等于限值」，按 4.1「超过」的字面含义判为**未超限**，是本次判定的关键边界，请复核时留意。
