# 机房设备巡检判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 节
- 数据：《巡检数据.csv》（未改动）
- 产出：《检修判定表.csv》（8 台设备，逐行判定）

## 一、判定所依据的约束

**结论值域**：需检修 / 无需检修 / 不适用（三选一）。

**条款清单**

| 条款 | 内容 | 条件 → 结论 |
|---|---|---|
| 4.1 | 停机检修判据（温度） | 运行温度 **超过** 额定温度上限 → 需检修 |
| 4.1 缺省 | 额定温度上限列为空时 | 按其 **机柜级限值** 执行：通用计算机柜 62 ℃；高密度 GPU 机柜 80 ℃ |
| 4.2 | 停机检修判据（告警） | 24 小时内告警 **≥3 次** → 需检修，**无论温度是否超限** |
| 4.3 | 排除条款 | 状态为「厂商保修返修中」→ **不纳入本次判定**，判为 不适用 |

**判定顺序**：4.3（排除）→ 4.2 → 4.1 → 默认「无需检修」。
理由：4.3 是排除条款，优先级最高；4.2 自带「无论温度是否超限」，说明它是独立于 4.1 的判据，命中即成立。一行可能同时命中 4.1 与 4.2，此时两者都记录在「触发条款」列。

**关于示例校准**：本次工作区只提供了规范与巡检数据，未附任何已判定的样表／案例，因此无法按工作方法用示例反推顺序；顺序改为依据规范条文自身的措辞（排除条款 + 「无论……均……」）确定。

**关于「超过」的边界**：规范用词是「**超过**」，即严格大于（>）。运行温度 **等于** 上限的，不触发 4.1。本批次 SV-201、SV-206 属于此类边界情形。

## 二、逐台说明

### SV-201 → 无需检修
额定温度上限列为空，按机柜级限值执行：机柜 A-01 用途「通用计算」→ 限值 62 ℃。
运行温度 62 ℃，**等于** 62 ℃，未「超过」，4.1 不触发；24h 告警 0 次 < 3 次，4.2 不触发；状态在用，4.3 不适用。
→ **无需检修**。

### SV-202 → 需检修（4.1）
额定温度上限列为空，机柜 A-01「通用计算」→ 限值 62 ℃。
运行温度 63 ℃ **＞** 62 ℃，超过机柜级限值，触发 4.1。
→ **需检修**。

### SV-203 → 需检修（4.2）
24h 告警 **3 次**，达到「≥3 次」门槛，触发 4.2（无论温度是否超限）。
另：额定温度上限列为空，机柜 A-02「高密度 GPU」→ 限值 80 ℃；运行温度 80 ℃ 等于 80 ℃，未超过，4.1 未触发。本例是「温度不超限但告警达标仍判检修」的情形，依据是 4.2 的独立判据。
→ **需检修**。

### SV-204 → 需检修（4.1、4.2 同时触发）
额定温度上限取表列值 90 ℃（该行有值，不再套机柜级限值）。
运行温度 95 ℃ **＞** 90 ℃，触发 4.1；24h 告警 **10 次 ≥ 3 次**，同时触发 4.2。
两条判据同向（都得检修），故「触发条款」列两者都记。
→ **需检修**。

### SV-205 → 不适用（4.3）
状态为「厂商保修返修中」，依 4.3 不纳入本次判定，判为不适用，优先级高于 4.1／4.2。
（附注：运行温度 68 ℃ 未超过额定 70 ℃，4.1 本也不触发；即便触发，仍应按 4.3 判不适用。）
→ **不适用**。

### SV-206 → 无需检修
额定温度上限取表列值 88 ℃（该行有值）。
运行温度 **88 ℃ 等于 88 ℃**，未「超过」，4.1 不触发；24h 告警 0 次 < 3 次；状态在用。
边界情形，勿因「到了上限数字」误判为超限。
→ **无需检修**。

### SV-207 → 无需检修
额定温度上限取表列值 72 ℃。
运行温度 71 ℃ 未超过 72 ℃，4.1 不触发；24h 告警 2 次 < 3 次，4.2 不触发。
→ **无需检修**。

### SV-208 → 无需检修（附规范缺口提示）
额定温度上限列为空，本应套机柜级限值；但该设备机柜 D-01 用途为「**存储专用**」，而现行规范 4.1 只列了「通用计算机柜 62 ℃」「高密度 GPU 机柜 80 ℃」，**没有存储专用机柜的限值**，无对应限值可套。

处理：运行温度 55 ℃ **低于** 已列出的任一限值（62 ℃ 与 80 ℃ 中最低的 62 ℃），故无论按哪一种口径都谈不上「超过」，4.1 不触发；24h 告警 0 次 < 3 次；状态在用。据此判**无需检修**。

**提示（建议报修时一并反馈）**：本行结论稳健（55 ℃ 远低于任一限值），但「存储专用机柜」缺少机柜级限值属于规范缺口。若以后该类机柜出现接近限值的温度，将无法依现行 v3.2 判定，建议在规范中补齐存储专用机柜的限值。
