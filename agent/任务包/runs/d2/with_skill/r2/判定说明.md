# 检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
- 数据：`巡检数据.csv`（本次巡检，只读未改）
- 结论值域：需检修 / 无需检修 / 不适用
- 判定顺序：**4.3（排除优先）→ 4.2（告警覆盖温度）→ 4.1（温度）**

## 一、依据的规范条款（逐条摘录）

| 条款 | 条件 | 结论 |
|---|---|---|
| 4.1 | 运行温度 **超过**（严格大于）额定温度上限 | 需检修 |
| 4.1（回退） | 额定温度上限列为空时，按**机柜级限值**执行：通用计算机柜 62 ℃、高密度GPU机柜 80 ℃ | — |
| 4.2 | 24h 告警 **≥3 次** | 需检修（**无论**温度是否超限） |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定，判**不适用** |

判定顺序说明：4.3 是适用范围排除，优先级最高；4.2 明确「无论温度是否超限」，故凡是告警 ≥3 次即需检修，无须再看温度；4.1 在无排除、无达到告警阈值时才起决定作用。

## 二、逐台判定

### SV-201｜无需检修
- 机柜 A-01，用途「通用计算」；额定温度上限**为空**，回退到机柜级限值 **62 ℃**。
- 运行温度 62 ℃，**未超过** 62 ℃（等于不算超过）；24h 告警 0 次 ＜ 3 次。
- 未触发任何条款 → **无需检修**。

### SV-202｜需检修
- 机柜 A-01，用途「通用计算」；额定值为空 → 机柜级限值 **62 ℃**。
- 运行温度 63 ℃ **＞ 62 ℃**，触发 **4.1** → **需检修**。

### SV-203｜需检修
- 机柜 A-02，用途「高密度GPU」；额定值为空 → 机柜级限值 **80 ℃**。
- 运行温度 80 ℃ 未超过 80 ℃；但 24h 告警 **3 次 ≥ 3 次**，触发 **4.2**（无论温度）→ **需检修**。
- 说明：温度本不构成检修依据，是 4.2 的告警阈值把它判进来的。

### SV-204｜需检修
- 机柜 B-01，用途「高密度GPU」，额定温度上限 **90 ℃**（该列有值，不回退）。
- 运行温度 95 ℃ **＞ 90 ℃**，触发 **4.1**；24h 告警 10 次 **≥ 3 次**，同时触发 **4.2** → **需检修**。

### SV-205｜不适用
- 机柜 B-02，用途「通用计算」，额定温度上限 **70 ℃**。
- 运行温度 68 ℃ 未超过 70 ℃；24h 告警 0 次 ＜ 3 次。单看温度与告警**本不需要检修**。
- 但状态为「**厂商保修返修中**」，按 **4.3** 不纳入本次判定 → **不适用**。
- 说明：这是 4.3 排除优先于 4.1/4.2 的体现，勿因温度正常而误判为「无需检修」。

### SV-206｜无需检修
- 机柜 C-01，用途「高密度GPU」，额定温度上限 **88 ℃**。
- 运行温度 88 ℃ **未超过** 88 ℃（等于不算超过）；24h 告警 0 次 ＜ 3 次 → **无需检修**。

### SV-207｜无需检修
- 机柜 C-02，用途「通用计算」，额定温度上限 **72 ℃**。
- 运行温度 71 ℃ ＜ 72 ℃；24h 告警 2 次 ＜ 3 次 → **无需检修**。

### SV-208｜不适用（规范覆盖盲区，建议报修前核实）
- 机柜 D-01，用途「**存储专用**」；额定温度上限**为空**，需回退到机柜级限值。
- 但规范 4.1 给出的机柜级限值只有两类：通用计算机柜 62 ℃、高密度GPU机柜 80 ℃；「存储专用」**不在其列**，故 **4.1 对本台无适用判据**，无法据温度下结论。
- 24h 告警 0 次 ＜ 3 次，不触发 4.2；状态「在用」，不触发 4.3。
- 由于没有可用的检修判据，按枚举中的「**不适用**」登记（不得在无依据时凭 55 ℃ 看起来很低就填「无需检修」）。
- **建议**：报修前向规范归口确认「存储专用机柜」的机柜级限值；该值一旦补充，本行应重判。
