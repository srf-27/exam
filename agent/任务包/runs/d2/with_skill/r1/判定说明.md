# 机房巡检判定说明

依据：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
数据：`巡检数据.csv`（本次巡检，共 8 台设备）
判定表：`检修判定表.csv`

## 一、判定所用规则

| 条款 | 触发条件 | 结论 |
|---|---|---|
| 4.1 | 运行温度 **超过**（严格大于）额定温度上限 | 需检修 |
| 4.1 回退 | 额定温度上限列为空时，改按机柜级限值：通用计算机柜 62℃、高密度 GPU 机柜 80℃ | —— |
| 4.2 | 24 小时内告警 **≥3 次**，无论温度是否超限 | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定，判「不适用」 |

判定顺序（按规范措辞确定）：**4.3 排除规则优先**——凡状态为「厂商保修返修中」的设备一律先判「不适用」，不再进入 4.1/4.2 的温度与告警比较；其余设备依次过 4.1、4.2，命中任一即为「需检修」，都不命中则「无需检修」。注意「超过」「≥」的边界：温度**等于**上限不算超限，告警**等于** 3 次即算触发。

## 二、逐台说明

### SV-201 —— 无需检修
- 额定温度上限为空，按 4.1 回退到机柜级限值；机柜 A-01 用途为通用计算 → 限值 62℃。
- 运行温度 62℃，**未超过** 62℃（等于上限，不触发 4.1）。
- 24h 告警 0 次 ＜ 3 次，不触发 4.2；状态「在用」。
- 未命中任何条款。

### SV-202 —— 需检修（触发 4.1）
- 额定温度上限为空，回退机柜级限值；机柜 A-01 通用计算 → 限值 62℃。
- 运行温度 63℃ **＞** 62℃，触发 4.1。
- 告警 0 次不触发 4.2，但已由 4.1 判定。

### SV-203 —— 需检修（触发 4.2）
- 额定温度上限为空，回退机柜级限值；机柜 A-02 用途为高密度 GPU → 限值 80℃。
- 运行温度 80℃，**未超过** 80℃（等于上限），**不**触发 4.1。
- 24h 告警 3 次 **≥ 3 次**，触发 4.2（规范明确「无论温度是否超限」）。
- 本行是「温度正常但告警达标仍要检修」的情形。

### SV-204 —— 需检修（同时触发 4.1 与 4.2）
- 额定温度上限 90℃ 为巡检记录值（非空），**不**适用机柜回退规则。
- 运行温度 95℃ **＞** 90℃，触发 4.1。
- 24h 告警 10 次 ≥ 3 次，同时触发 4.2。
- 两条款均命中且结论一致，判需检修。

### SV-205 —— 不适用（适用 4.3）
- 状态为「厂商保修返修中」，按 4.3 不纳入本次判定，判「不适用」。
- 4.3 是排除规则，优先执行：该机虽温度 68℃ 未超额定 70℃、告警 0 次，本不触发 4.1/4.2，但状态一栏直接决定结论为「不适用」，不参与检修判定。

### SV-206 —— 无需检修
- 额定温度上限 88℃ 为记录值（非空）。
- 运行温度 88℃，**未超过** 88℃（等于上限），不触发 4.1。
- 24h 告警 0 次 ＜ 3 次；状态「在用」。未命中任何条款。

### SV-207 —— 无需检修
- 额定温度上限 72℃ 为记录值（非空）。
- 运行温度 71℃ 未超过 72℃，不触发 4.1。
- 24h 告警 2 次 ＜ 3 次；状态「在用」。未命中任何条款。

### SV-208 —— 无需检修（回退规则无适用限值，按无条款命中处理）
- 额定温度上限为空，本应回退机柜级限值；但机柜 D-01 用途为「存储专用」，**不在规范给出的两类机柜级限值（通用计算机柜 62℃、高密度 GPU 机柜 80℃）之内**，因此没有可用的温度限值，无法据 4.1 作出超限判断。
- 即便按已给出的两类限值中较宽的一档（80℃）参照，运行温度 55℃ 也远低于限值，不构成超限。
- 24h 告警 0 次 ＜ 3 次，不触发 4.2；状态「在用」，不适用 4.3。
- 综上未命中任何条款，判「无需检修」。

## 三、备注
