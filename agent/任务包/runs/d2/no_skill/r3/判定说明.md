# 机房设备检修判定说明

判定依据：《机房设备维护规范 v3.2》第 4 节停机检修判据；数据来源：`巡检数据.csv`。
判定取值：需检修 / 无需检修 / 不适用。

## 判据要点

- **4.1**：运行温度**超过**额定温度上限 → 需检修。额定上限取巡检数据表对应行；该列为空的，按机柜级限值执行（通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃）。注意是「超过」，温度**等于**限值不算超限。
- **4.2**：24 小时内告警 **≥3 次** → 需检修，无论温度是否超限。注意含 =3 次。
- **4.3**：状态为「厂商保修返修中」→ 不纳入本次判定，判「不适用」。

## 逐台说明

### SV-201 —— 无需检修
- 机柜 A-01 为通用计算机柜，本行额定上限为空，故适用机柜级限值 **62 ℃**。
- 运行温度 62 ℃：62 > 62 **不成立**，未超限。
- 24h 告警 0 次，未达 3 次。
- 无条款触发，判**无需检修**。

### SV-202 —— 需检修
- 机柜 A-01 通用计算机柜，额定上限为空，适用机柜级限值 **62 ℃**。
- 运行温度 63 ℃：63 > 62 **成立**，超限 → 触发 **4.1**。
- 判**需检修**。

### SV-203 —— 需检修
- 机柜 A-02 高密度 GPU 机柜，额定上限为空，适用机柜级限值 **80 ℃**。
- 运行温度 80 ℃：80 > 80 **不成立**，仅按 4.1 不超限。
- 但 24h 告警 **3 次**，满足「≥3 次」→ 触发 **4.2**，无论温度是否超限均判需检修。
- 判**需检修**（依据告警条款，非温度条款）。

### SV-204 —— 需检修
- 本行额定温度上限为 90 ℃（非空，直接适用），运行温度 95 ℃：95 > 90 **成立** → 触发 **4.1**。
- 同时 24h 告警 **10 次** ≥3 → 触发 **4.2**。
- 两条判据均触发，判**需检修**。

### SV-205 —— 不适用
- 状态为「厂商保修返修中」，依据 **4.3** 不纳入本次判定，判**不适用**。
- 备注：其温度 68 ℃、告警 0 次虽看似正常，但按规范 4.3 优先排除，不参与本表判定。

### SV-206 —— 无需检修
- 额定上限 88 ℃，运行温度 88 ℃：88 > 88 **不成立**，未超限。
- 24h 告警 0 次，未达 3 次。
- 无条款触发，判**无需检修**。

### SV-207 —— 无需检修
- 额定上限 72 ℃，运行温度 71 ℃：71 > 72 **不成立**，未超限。
- 24h 告警 2 次，未达 3 次（2 < 3）。
- 无条款触发，判**无需检修**。

### SV-208 —— 无需检修（附规范待补事项，请留意）
- 机柜 D-01 用途为**存储专用**，本行额定温度上限为空。
- 规范 4.1 规定额定上限为空时「按其机柜级限值执行」，但规范只给出两类机柜级限值：通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃，**未定义存储专用机柜的机柜级限值**，因此 4.1 对该设备缺乏可直接套用的限值。
- 实际数值：运行温度 **55 ℃**，24h 告警 0 次，状态在用。55 ℃ 低于规范已定义的最低限值（62 ℃），无论按哪种既有口径都不会超限；4.2、4.3 亦未触发。
- 综合判**无需检修**。但严格讲这是一处规范空白：判定结论依赖「55 ℃ 远低于任一定义限值」的常识判断，而非规范明确给出的限值。
- **建议**：报修前请规范归口人补充「存储专用机柜」的机柜级限值，或在本行补填额定温度上限，以免后续巡检出现存储专用设备温度接近 60 ℃ 时无法判定。
