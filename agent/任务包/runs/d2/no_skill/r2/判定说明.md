# 机房设备检修判定说明

- 判定依据：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
- 数据来源：`巡检数据.csv`（本月巡检数据）
- 判定结果：见 `检修判定表.csv`
- 判定日期：2026-09-29

## 一、判定规则回顾

| 条款 | 内容 | 本次判定中的用法 |
|---|---|---|
| 4.1 | 运行温度**超过**额定温度上限 → 需检修 | 额定温度上限列为空的设备，改用**机柜级限值**；机柜级限值：通用计算机柜 62℃、高密度GPU机柜 80℃ |
| 4.2 | 24 小时内告警 **≥3 次** → 需检修 | 与温度是否超限无关，单独成立 |
| 4.3 | 状态为「厂商保修返修中」→ 不适用 | 优先排除，不参与本次判定 |

两点需要注意的判定口径：

1. **4.1 是「超过」而非「达到」**。运行温度等于限值时不算超限，判为无需检修（SV-201、SV-203、SV-206 都属于这种情况）。
2. **4.1 与 4.2 是并列触发**。任一条成立即为「需检修」，两条同时成立时两条都记录（SV-204）。

## 二、逐台判定

### SV-201 → 无需检修
- 机柜 A-01，用途为通用计算，属**通用计算机柜**；其「额定温度上限」列为空，故按机柜级限值 **62℃** 执行。
- 运行温度 **62℃**，与限值相等，**未超过** 62℃，4.1 不触发。
- 24h 告警 **0 次** < 3 次，4.2 不触发。
- 结论：无需检修。

### SV-202 → 需检修
- 机柜 A-01，同为通用计算机柜，限值 **62℃**。
- 运行温度 **63℃** > 62℃，**超限**，触发 **4.1**。
- 告警 0 次，4.2 不触发，但不影响结论。
- 结论：需检修（触发条款 4.1）。

### SV-203 → 需检修
- 机柜 A-02，用途为高密度GPU，属**高密度GPU机柜**；额定温度上限列为空，按机柜级限值 **80℃** 执行。
- 运行温度 **80℃**，与限值相等，未超过 80℃，**4.1 不触发**。
- 但 24h 告警 **3 次**，达到「≥3 次」的门槛，触发 **4.2**。
- 结论：需检修（触发条款 4.2）。此台属于"温度没超但告警够数"的情形，易被漏判。

### SV-204 → 需检修
- 该台「额定温度上限」列**有值 90℃**，因此不适用机柜级限值，直接与 90℃ 比较。
- 运行温度 **95℃** > 90℃，超限，触发 **4.1**。
- 24h 告警 **10 次** ≥ 3 次，同时触发 **4.2**。
- 结论：需检修（4.1、4.2 两条同时触发）。本台超限幅度（+5℃）与告警量（10 次）均为全场最高，建议报修时列为优先项。

### SV-205 → 不适用
- 状态为「**厂商保修返修中**」，按 **4.3** 不纳入本次判定。
- 供参考：其额定温度上限 70℃、运行温度 68℃（未超限）、告警 0 次，即使不适用 4.3 也不会触发 4.1/4.2。
- 结论：不适用（触发条款 4.3）。

### SV-206 → 无需检修
- 额定温度上限 **88℃**（有值）。
- 运行温度 **88℃**，与限值相等，**未超过** 88℃，4.1 不触发。
- 24h 告警 **0 次** < 3 次，4.2 不触发。
- 结论：无需检修。此台数值贴近上限但不等于超限，无需报修。

### SV-207 → 无需检修
- 额定温度上限 **72℃**（有值）。
- 运行温度 **71℃** ≤ 72℃，未超限，4.1 不触发。
- 24h 告警 **2 次** < 3 次，4.2 不触发。
- 结论：无需检修。告警 2 次距离门槛仅差 1 次，建议下月巡检重点留意。

### SV-208 → **无法判定（规范未覆盖），已标记「待确认」**
- 该台「额定温度上限」列为空（55℃ 是运行温度），按 4.1 应「按其机柜级限值执行」。
- 但规范 4.1 只给出了两类机柜级限值：**通用计算机柜 62℃**、**高密度GPU机柜 80℃**。SV-208 所在机柜 D-01 的用途是「**存储专用**」，**不属于上述任何一类，规范中无对应限值**。
- 因此本台既无法确认温度是否超限，也就无法在「需检修 / 无需检修 / 不适用」中作出有依据的选择。
- 处理方式：**未强行填写三选一的结果**，在判定表中标记为「待确认」，留待确认后再补判。
- 需确认的问题：存储专用机柜的机柜级温度限值是多少？（若按通用计算机柜 62℃ 执行，则 55℃ 未超限，应判无需检修；但这是我的推测，规范中没有依据，不作为结论。）

## 三、汇总

| 判定 | 台数 | 设备 |
|---|---|---|
| 需检修 | 3 | SV-202（4.1）、SV-203（4.2）、SV-204（4.1+4.2） |
| 无需检修 | 3 | SV-201、SV-206、SV-207 |
| 不适用 | 1 | SV-205（4.3） |
| 待确认 | 1 | SV-208（规范未覆盖存储专用机柜限值） |

**报修建议顺序**：SV-204（超限 +5℃，告警 10 次）> SV-202（超限 +1℃）> SV-203（温度临界 80℃，告警 3 次）。

## 四、需要提请规范维护方澄清的两点

1. **存储专用机柜（及其他未列明用途的机柜）缺机柜级温度限值**，导致 SV-208 无法判定。建议在规范 4.1 中补齐，或在巡检数据表中为该类设备直接填列额定温度上限。
2. 本次判定中 SV-201、SV-203、SV-206 三台的运行温度**恰好等于**限值。本次按「超过」的字面含义（严格大于）判为未超限。若实际执行中采用「达到即超限」的口径，这三台的结论会改变（分别变为需检修、需检修、需检修）。建议明确口径。
