# 机房设备检修判定说明

- 依据文件：《机房设备维护规范 v3.2（现行）》第 4 章「停机检修判据」
- 数据来源：《巡检数据.csv》（2026-09 巡检）
- 判定日期：2026-09-29

## 一、判据摘要

| 条款 | 判据 | 结论 |
| --- | --- | --- |
| 4.1 | 运行温度**超过**额定温度上限 | 需检修 |
| 4.1（补充） | 额定温度上限列为空的，按其机柜级限值执行：通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃ | —— |
| 4.2 | 24h 告警**≥3 次**（与温度是否超限无关） | 需检修 |
| 4.3 | 状态为「厂商保修返修中」 | 不适用（不纳入本次判定） |

两个口径要点：

1. **「超过」按严格大于理解。** 运行温度**等于**额定上限不算超限，不触发 4.1。
2. **4.2 为独立触发条件。** 即使温度未超限，只要 24h 告警 ≥3 次也判需检修。

## 二、逐台判定

### SV-201 —— 无需检修
- 机柜 A-01，用途「通用计算」；额定温度上限列为空 → 按机柜级限值 **62 ℃** 执行。
- 运行温度 62 ℃，**未超过** 62 ℃（等于不算超），4.1 不成立。
- 24h 告警 0 次 ＜ 3，4.2 不成立；状态「在用」，4.3 不成立。
- **结论：无需检修。**

### SV-202 —— 需检修（4.1）
- 机柜 A-01，用途「通用计算」；额定温度上限列为空 → 按机柜级限值 **62 ℃** 执行。
- 运行温度 63 ℃ **＞** 62 ℃，超过额定上限，**4.1 成立**。
- 24h 告警 0 次，未触发 4.2。
- **结论：需检修（温度超限）。**

### SV-203 —— 需检修（4.2）
- 机柜 A-02，用途「高密度 GPU」；额定温度上限列为空 → 按机柜级限值 **80 ℃** 执行。
- 运行温度 80 ℃，**未超过** 80 ℃（等于不算超），4.1 不成立。
- 24h 告警 **3 次 ≥ 3**，**4.2 成立**。
- **结论：需检修（告警频次超限，温度非触发因素）。**

### SV-204 —— 需检修（4.1、4.2 同时成立）
- 机柜 B-01，用途「高密度 GPU」；额定温度上限 90 ℃。
- 运行温度 95 ℃ **＞** 90 ℃，**4.1 成立**。
- 24h 告警 **10 次 ≥ 3**，**4.2 亦成立**。
- **结论：需检修（温度超限且告警频发，属本次最严重设备）。**

### SV-205 —— 不适用（4.3）
- 状态为「厂商保修返修中」。
- 4.3 规定该状态设备不纳入本次判定，故**不再核对其温度与告警**。
- **结论：不适用。**

### SV-206 —— 无需检修
- 机柜 C-01，用途「高密度 GPU」；额定温度上限 88 ℃（该列非空，直接采用本机限值）。
- 运行温度 88 ℃，**未超过** 88 ℃（等于不算超），4.1 不成立。
- 24h 告警 0 次；状态「在用」。
- **结论：无需检修。**

### SV-207 —— 无需检修
- 机柜 C-02，用途「通用计算」；额定温度上限 72 ℃。
- 运行温度 71 ℃，未超过 72 ℃，4.1 不成立。
- 24h 告警 2 次 ＜ 3，**未达 4.2 阈值**，4.2 不成立；状态「在用」。
- **结论：无需检修。**

### SV-208 —— **无法依据现行规范判定（表中暂填「不适用」，待确认）**
- 机柜 D-01，用途「**存储专用**」；额定温度上限列为空 → 按规范需改「机柜级限值」，**但规范只给出了两档机柜级限值**：
  - 通用计算机柜 62 ℃
  - 高密度 GPU 机柜 80 ℃
  - **未规定「存储专用」机柜的限值。**
- 因此 4.1 **对本机无可用阈值**，既不能判超限、也不能判未超限。本机运行温度 55 ℃、告警 0 次、状态「在用」——即便数值看起来偏低，也不宜据此直接下「无需检修」结论，否则等于擅自替规范补了一个 62 ℃ 的阈值。
- 4.2（0 次 ＜ 3）、4.3（非返修）均不成立。
- **结论：规范存在缺口，本条判定待确认。** 表中为满足「只填三值」的填报要求暂填「**不适用**」（含义为「无适用条款」），与 SV-205 因保修而「不适用」的性质不同，请在报修前向规范制定方确认存储专用机柜的限值。
