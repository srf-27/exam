# 机房设备检修判定说明

- 依据：《机房设备维护规范 v3.2》第 4 章「停机检修判据」
- 数据来源：巡检数据.csv（本月巡检）
- 判定口径：
  - 4.1 运行温度**超过**额定温度上限 → 需检修（"超过"按严格大于处理，等于限值不触发）；
    额定温度上限为空时，改用机柜级限值：通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃。
  - 4.2 24 小时内告警 **≥3 次** → 需检修，与温度是否超限无关。
  - 4.3 状态为「厂商保修返修中」→ 不纳入本次判定，判「不适用」（优先于 4.1、4.2）。
  - 以上均不满足者，判「无需检修」。

## 逐台说明

### SV-201 → 无需检修
A-01 机柜、通用计算。额定温度上限列为空，按通用计算机柜限值 62 ℃ 执行。运行温度 62 ℃，未超过 62 ℃（临界但未超限），不触发 4.1；24h 告警 0 次 < 3 次，不触发 4.2。故无需检修。

### SV-202 → 需检修（触发 4.1）
A-01 机柜、通用计算。额定温度上限列为空，按通用计算机柜限值 62 ℃ 执行。运行温度 63 ℃ > 62 ℃，超过限值，触发 4.1。（告警 0 次，未触发 4.2。）

### SV-203 → 需检修（触发 4.2）
A-02 机柜、高密度 GPU。额定温度上限列为空，按高密度 GPU 机柜限值 80 ℃ 执行。运行温度 80 ℃，未超过 80 ℃，不触发 4.1；但 24h 告警 3 次 ≥ 3 次，触发 4.2，故需检修。

### SV-204 → 需检修（触发 4.1、4.2）
B-01 机柜、高密度 GPU。本行额定温度上限为 90 ℃（非空），按本行值执行，不套用机柜级限值。运行温度 95 ℃ > 90 ℃，触发 4.1；24h 告警 10 次 ≥ 3 次，同时触发 4.2。两项判据均命中，需检修。

### SV-205 → 不适用（触发 4.3）
B-02 机柜、通用计算。额定温度上限 70 ℃、运行温度 68 ℃（未超限）、24h 告警 0 次，按 4.1/4.2 本不构成检修；但状态为「厂商保修返修中」，依 4.3 不纳入本次判定，判「不适用」。该机维修记录另行跟踪，不计入本次报修。

### SV-206 → 无需检修
C-01 机柜、高密度 GPU。本行额定温度上限为 88 ℃（非空）。运行温度 88 ℃，未超过 88 ℃（临界但未超限），不触发 4.1；24h 告警 0 次 < 3 次，不触发 4.2。故无需检修。

### SV-207 → 无需检修
C-02 机柜、通用计算。本行额定温度上限为 72 ℃（非空）。运行温度 71 ℃ ≤ 72 ℃，不触发 4.1；24h 告警 2 次 < 3 次，不触发 4.2。故无需检修。

### SV-208 → 无需检修
D-01 机柜、存储专用。额定温度上限列为空，需按机柜级限值执行，但规范只列明了通用计算机柜（62 ℃）与高密度 GPU 机柜（80 ℃）两类，**存储专用柜未列明限值**，存在口径空白。本次按最保守方式处理：运行温度 55 ℃ 低于所列限值中的最低值 62 ℃，无论采用何种合理限值均不超限，不触发 4.1；24h 告警 0 次 < 3 次，不触发 4.2。故无需检修。**建议**：补充存储专用机柜的机柜级限值，以免后续出现临界值设备时无法判定。

## 待规范确认事项

1. **存储专用机柜限值缺失（SV-208）**：规范 4.1 只定义了通用计算（62 ℃）和高密度 GPU（80 ℃）两类机柜级限值，存储专用柜无对应限值。本台因数值明显偏低不影响结论，但该口径空白建议补全。
2. **临界值判定（SV-201、SV-203、SV-206）**：三台设备的温度恰好等于限值（62/80/88 ℃）。本次按 4.1「超过」的字面含义，等于限值不判超限。若实际执行口径为「达到即检修」，则 SV-201、SV-203、SV-206 需改判（其中 SV-203 已因告警 4.2 判需检修，结论不变）。建议明确"超过"是否含等于。
