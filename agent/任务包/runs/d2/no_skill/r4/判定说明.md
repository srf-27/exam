# 机房设备检修判定说明

**依据规范：**《机房设备维护规范 v3.2（现行）》第 4 章
**数据来源：** `巡检数据.csv`（2026-09 巡检）
**判定日期：** 2026-09-29

## 判定规则回顾

- **4.1（温度）** 运行温度**超过**额定温度上限 → 需检修。额定上限见巡检数据对应行；**该列为空**的设备，按其**机柜级限值**执行——通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。
- **4.2（告警）** 24 小时内告警 **≥3 次** → 需检修，无论温度是否超限。
- **4.3（状态）** 状态为「厂商保修返修中」→ 不纳入本次判定，判「不适用」。

两处边界口径，为便于复核先说明：4.1 是"**超过**"，故运行温度**等于**上限不算超限；4.2 是"**≥3 次**"，故 3 次即触发、2 次不触发。

## 逐台说明

### SV-201 → 无需检修（条款 4.1）
额定温度上限列为空，按机柜用途"通用计算"取机柜级限值 62 ℃。运行温度 62 ℃，与限值相等，未"超过"。24h 告警 0 次，不触发 4.2。故无需检修。

### SV-202 → 需检修（条款 4.1）
额定温度上限列为空，按通用计算机柜限值 62 ℃。运行温度 **63 ℃ > 62 ℃**，超过限值，触发 4.1。告警 0 次不构成另一条判据。判需检修。与 SV-201 同机柜、仅 1 ℃ 之差，恰好跨过阈值。

### SV-203 → 需检修（条款 4.2）
额定温度上限列为空，按机柜用途"高密度 GPU"取机柜级限值 80 ℃。运行温度 80 ℃，与限值相等，**未**触发 4.1。但 24h 告警 **3 次 ≥ 3 次**，触发 4.2。4.2 不要求温度超限，故仍判需检修——这正是 4.2 作为独立判据的意义：温度在限值内但告警频繁，同样要停机检修。

### SV-204 → 需检修（条款 4.1、4.2）
该行填有额定温度上限 90 ℃，直接适用（无需回退机柜级限值）。运行温度 **95 ℃ > 90 ℃**，触发 4.1；24h 告警 **10 次 ≥ 3 次**，同时触发 4.2。两条判据均命中，为本轮唯一双重触发设备。

### SV-205 → 不适用（条款 4.3）
状态为「厂商保修返修中」，按 4.3 不纳入本次判定。需注意：该行温度（68 ℃，限值 70 ℃）与告警（0 次）本身均不触发判据，但**判定结论按 4.3 出「不适用」，而非按温度出「无需检修」**——设备已送修，不属本次报修范围。

### SV-206 → 无需检修（条款 4.1）
该行填有额定温度上限 88 ℃，直接适用。运行温度 88 ℃，与限值相等，未"超过"。24h 告警 0 次。故无需检修。与 SV-203 同为"顶到上限"，但 SV-203 另有告警触发，两者结果不同。

### SV-207 → 无需检修（条款 4.1）
该行填有额定温度上限 72 ℃，直接适用。运行温度 71 ℃，低于限值。24h 告警 2 次，**小于 3 次**，不触发 4.2。故无需检修。距两条阈值都只差一档，建议下轮巡检关注。

### SV-208 → 无法判定（规范缺口，待补充判据）
本行**无法给出三选一的结论**，原因如下：
1. 额定温度上限列为空，按 4.1 应回退到机柜级限值；
2. 机柜用途为"**存储专用**"，而规范 4.1 只定义了"通用计算机柜 62 ℃"和"高密度 GPU 机柜 80 ℃"两类，**没有存储专用机柜的限值**；
3. 因此运行温度 55 ℃ 是否超限，**在现行规范下不可判定**。24h 告警 0 次（不触发 4.2）、状态在用（不触发 4.3）均不构成判据。

该行**不是** 4.3 所指的"不适用"，也**不应**未经依据就归入"无需检修"。表格中该行判定列**留空**，未用三个选项中的任何一个硬套。

**建议：** 报修前请规范制定方补充"存储专用机柜"的机柜级温度限值，再据以判定。若 55 ℃ 低于该限值，则为无需检修。
