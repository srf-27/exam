# 机房设备巡检判定说明

依据《机房设备维护规范 v3.2》第 4 节「停机检修判据」，对巡检数据逐台判定，结果填入 `检修判定表.csv`。

## 判定顺序

一行数据可能同时命中多条判据，本次采用的顺序为：

1. **4.3 排除（最高优先）**：状态为「厂商保修返修中」的设备**不纳入本次判定**，直接判「不适用」，不再看温度与告警。
2. **4.2 告警**：24h 告警 ≥3 次，无论温度是否超限，判「需检修」。
3. **4.1 温度**：运行温度**超过**额定温度上限的，判「需检修」。

「超过」为严格大于，等于上限不触发。额定温度上限为空时，回退到机柜级限值：通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃。

## 逐台说明

### SV-301 — 需检修（4.1）
通用计算机柜。本行「额定温度上限」为空，按回退规则取机柜级限值 62 ℃。运行温度 65 ℃ ＞ 62 ℃，触发 4.1。

### SV-302 — 需检修（4.1）
本行额定上限 70 ℃，运行温度 72 ℃ ＞ 70 ℃，触发 4.1。告警 0 次，与结论无关。

### SV-303 — 无需检修
额定上限 70 ℃，运行温度 69 ℃，未超过；24h 告警 1 次 ＜ 3 次，未触发 4.2；状态在用。不命中任何判据。

### SV-304 — 需检修（4.2）
24h 告警 3 次，满足「≥3 次」，触发 4.2，判需检修。运行温度 69 ℃ 未超过额定上限 70 ℃，但 4.2 明示「无论温度是否超限」，故结论由 4.2 决定。

### SV-305 — 不适用（4.3）
状态为「厂商保修返修中」，依 4.3 不纳入本次判定，判「不适用」。其运行温度 79 ℃ 也未超过高密度 GPU 机柜级限值 80 ℃，但不参与判定。

### SV-306 — 需检修（4.1）
高密度 GPU 机柜。本行额定上限为空，按回退规则取机柜级限值 80 ℃。运行温度 81 ℃ ＞ 80 ℃，触发 4.1。

### SV-307 — 无需检修
本行额定上限 85 ℃，运行温度 85 ℃。规范用「超过」，85 ℃ 并未超过 85 ℃，故不触发 4.1；24h 告警 2 次 ＜ 3 次，不触发 4.2；状态在用。判无需检修。此为边界值，关键是严格大于而非大于等于。

### SV-308 — 无需检修
额定上限 68 ℃，运行温度 66 ℃，未超过；24h 告警 0 次，未触发 4.2；状态在用。

### SV-309 — 不适用（4.3）
24h 告警 7 次已满足 4.2 的「≥3 次」，但状态为「厂商保修返修中」。依 4.3「不纳入本次判定」，排除优先于 4.2，故判「不适用」，而非「需检修」。此台是唯一同时命中 4.2 与 4.3 的冲突行，结论站在 4.3 一边。

### SV-310 — 需检修（4.1）
额定上限 92 ℃，运行温度 99 ℃ ＞ 92 ℃，触发 4.1。
