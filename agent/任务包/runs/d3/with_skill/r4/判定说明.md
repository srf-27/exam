# 机房设备巡检判定说明

- 依据：《机房设备维护规范 v3.2》第 4 章「停机检修判据」
- 数据：`巡检数据.csv`（只读，未改动）；结论填入 `检修判定表.csv`
- 判定顺序：**先 4.3 排除（厂商保修返修中 → 不适用），再 4.1 温度、4.2 告警**（任意一条成立即需检修）

## 判据要点

1. **4.1 温度**：运行温度 **严格大于** 额定温度上限才判需检修（等于上限不算超限）。额定温度上限列为空时，回退用机柜级限值：通用计算机柜 **62 ℃**、高密度 GPU 机柜 **80 ℃**。
2. **4.2 告警**：24 小时内告警 **≥3 次**，无论温度是否超限，均判需检修。
3. **4.3 排除**：状态为「厂商保修返修中」的设备不纳入本次判定，判「不适用」——该状态优先于 4.1、4.2。

## 涉及的边界与优先规则

- **等于上限不判**：SV-307 运行温度恰为 85 ℃、等于额定上限，因 4.1 用「超过」而非「达到」，判无需检修。
- **空值回退**：SV-301、SV-306 额定上限为空，分别按各自机柜用途（通用计算 / 高密度 GPU）的机柜级限值执行。
- **排除优先**：SV-305、SV-309 均为返修中设备，尽管 SV-309 告警超标，仍依 4.3 判「不适用」。

## 汇总

- 需检修：SV-301、SV-302、SV-304、SV-306、SV-310（共 5 台）
- 无需检修：SV-303、SV-307、SV-308（共 3 台）
- 不适用：SV-305、SV-309（共 2 台）
