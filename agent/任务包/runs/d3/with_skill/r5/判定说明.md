# 机房设备判定说明

- 依据：《机房设备维护规范 v3.2》第 4 节「停机检修判据」
- 数据：《巡检数据.csv》
- 判定值域：需检修 / 无需检修 / 不适用
- 日期：2026-09-29

## 一、判定顺序（先定顺序，再逐行判）

同一台设备可能同时命中多条条款，本次判定按以下优先级执行：

1. **4.3 优先**：状态为「厂商保修返修中」的设备，无论温度、告警如何，一律判「不适用」，不纳入本次判定。
2. **4.2 与 4.1 并列指向「需检修」**：两者任一命中即需检修；若仅 4.2 命中，触发条款记 4.2，反之记 4.1。
3. 以上均未命中，判「无需检修」。

顺序的确定依据：SV-309 同时命中 4.2（告警 7 次）与 4.3（返修中），最终结论取 4.3，故 4.3 排在 4.2 之前。

**语义约定**：4.1 的「超过」为严格大于（等于上限不算超限），4.2 的「≥3 次」为大于等于 3。

**回退规则（4.1 从句）**：额定温度上限一列为空时，不按空值处理，改按机柜级限值执行——通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃。

### SV-301 — 需检修（4.1）

额定温度上限为空，按回退规则取通用计算机柜限值 62 ℃。运行温度 65 ℃ > 62 ℃，超限，判需检修。该行是「上限列为空」的典型，若漏掉 4.1 的回退从句会无从判断。

### SV-302 — 需检修（4.1）

额定上限 70 ℃，运行温度 72 ℃ > 70 ℃，超温，判需检修。告警 0 次不影响结论。

### SV-303 — 无需检修

运行温度 69 ℃ ≤ 上限 70 ℃，未超温；24h 告警 1 次 < 3 次。4.1、4.2 均未命中，判无需检修。

### SV-304 — 需检修（4.2）

运行温度 69 ℃ ≤ 上限 70 ℃，未超温，4.1 不命中；但 24h 告警 3 次 ≥ 3 次，命中 4.2，判需检修。此例说明告警条款独立于温度。

### SV-305 — 不适用（4.3）

状态为「厂商保修返修中」，按 4.3 不纳入本次判定，判不适用。温度 79 ℃ 未超 GPU 机柜限值 80 ℃，但即便超限也仍应判不适用——4.3 优先。

### SV-306 — 需检修（4.1）

额定温度上限为空，按回退规则取高密度 GPU 机柜限值 80 ℃。运行温度 81 ℃ > 80 ℃，超限，判需检修。注意机柜用途为高密度 GPU，回退限值取 80 ℃ 而非 62 ℃。

### SV-307 — 无需检修

运行温度 85 ℃，等于上限 85 ℃。4.1 的「超过」为严格大于，等于不算超限；24h 告警 2 次 < 3 次。故判无需检修。

### SV-308 — 无需检修

运行温度 66 ℃ ≤ 上限 68 ℃，未超温；告警 0 次 < 3 次。判无需检修。

### SV-309 — 不适用（4.3）

24h 告警 7 次虽已命中 4.2，但状态为「厂商保修返修中」，按 4.3 优先不纳入本次判定，判不适用。此例演示排除规则优先于触发规则。

### SV-310 — 需检修（4.1）

额定上限 92 ℃，运行温度 99 ℃ > 92 ℃，超温 7 ℃，判需检修。虽用高密度 GPU 机柜，但该行额定上限有值（92 ℃），不适用回退限值。

- 无需检修：SV-303、SV-307、SV-308（共 3 台）
- 不适用：SV-305、SV-309（共 2 台）
