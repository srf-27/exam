# 机房设备检修判定说明

依据：《机房设备维护规范 v3.2》第 4 章「停机检修判据」；数据源：`巡检数据.csv`。
判定值域：需检修 / 无需检修 / 不适用。

## 判定规则与顺序

1. **4.3（最先适用）**：状态为「厂商保修返修中」的设备**不纳入本次判定**，一律判「不适用」。该条为排除条款，优先于 4.1、4.2。
2. **4.1**：运行温度**超过**（严格大于）额定温度上限的，判「需检修」。
   - 回退规则：额定温度上限列为空时，取机柜级限值——通用计算机柜 62 ℃、高密度 GPU 机柜 80 ℃（按数据表「机柜用途」列匹配）。
3. **4.2**：24 小时内告警 **≥3 次**的，无论温度是否超限，均判「需检修」。
4. 以上均不触发的，判「无需检修」。

同一行同时命中多条时，顺序为 **4.3 >（4.1 / 4.2）> 无需检修**。数据中 `SV-309`（告警 7 次、返修中）与 `SV-305`（温度未超限、返修中）即用于校验该顺序：二者均以 4.3 排除收尾。

## 备注

- 4.1 的关键词是「超过」，故取严格大于；温度恰好等于上限（SV-307）不触发。
- 「额定温度上限」为空的行（SV-301、SV-305、SV-306）必须走回退规则，不得因缺数据而搁置判定。
- 全部 10 台设备均有结论，无空缺、无值域外取值。
