# 机房设备检修判定说明

- 依据：《机房设备维护规范 v3.2（现行）》第 4 节「停机检修判据」
- 数据来源：`巡检数据.csv`（本次月度巡检）
- 判定口径：
  - 4.1 运行温度 **超过** 额定温度上限 → 需检修；额定温度上限为空时，按机柜级限值执行（通用计算机柜 62℃，高密度 GPU 机柜 80℃）。
  - 4.2 24 小时内告警 **≥3 次** → 需检修，不论温度是否超限。
  - 4.3 状态为「厂商保修返修中」→ 不适用，不纳入本次判定。
  - 判定优先级：先按 4.3 排除返修设备，再对在用设备同时核对 4.1、4.2，任一触发即判「需检修」。注意 4.1 是「超过」（>），等于限值不判检修。

共 10 台：需检修 5 台（SV-301、SV-302、SV-304、SV-306、SV-310），无需检修 3 台（SV-303、SV-307、SV-308），不适用 2 台（SV-305、SV-309）。

---

## 需检修（5 台）

### SV-301 ｜ 4.1
- 机柜 A-01 为通用计算，额定温度上限列为空 → 按机柜级限值 **62℃**。
- 运行温度 **65℃ > 62℃**，超出 3℃。
- **判定：需检修。**

### SV-302 ｜ 4.1
- 额定温度上限 70℃，运行温度 **72℃ > 70℃**，超出 2℃。
- 24h 告警 0 次，不涉及 4.2。
- **判定：需检修。**

### SV-304 ｜ 4.2
- 运行温度 69℃ ≤ 额定上限 70℃，**温度本身未超限**。
- 但 24h 告警 **3 次 ≥ 3 次**，按 4.2 规定「无论温度是否超限」均判需检修。
- **判定：需检修（触发条款为 4.2，不是 4.1）。**

### SV-306 ｜ 4.1
- 机柜 B-01 为高密度 GPU，额定温度上限列为空 → 按机柜级限值 **80℃**（不是通用机柜的 62℃）。
- 运行温度 **81℃ > 80℃**，超出 1℃。
- **判定：需检修。**

### SV-310 ｜ 4.1
- 额定温度上限 92℃，运行温度 **99℃ > 92℃**，超出 7℃，为本次超限幅度最大的一台。
- 24h 告警 0 次，不涉及 4.2。
- **判定：需检修。**

## 无需检修（3 台）

### SV-303 ｜ 未触发条款
- 运行温度 69℃ ≤ 额定上限 70℃，未超限。
- 24h 告警 1 次 < 3 次，未触发 4.2。
- **判定：无需检修。**

### SV-307 ｜ 未触发条款
- 运行温度 **85℃ = 额定上限 85℃**。4.1 的措辞是「超过」，等于限值不算超过，故不判检修。
- 24h 告警 2 次 < 3 次，未触发 4.2。
- 提示：该机运行温度已贴限值运行，虽本次判无需检修，建议列入下月重点观察。
- **判定：无需检修。**

### SV-308 ｜ 未触发条款
- 运行温度 66℃ ≤ 额定上限 68℃。
- 24h 告警 0 次。
- **判定：无需检修。**

## 不适用（2 台）

### SV-305 ｜ 4.3
- 状态为「厂商保修返修中」，按 4.3 不纳入本次判定，判「不适用」。
- 备注：其运行温度 79℃ ≤ 高密度 GPU 机柜限值 80℃，即便按 4.1 核对也未超限；本次的「不适用」纯粹由 4.3 状态条款决定。
- **判定：不适用。**

### SV-309 ｜ 4.3
- 状态为「厂商保修返修中」，按 4.3 判「不适用」。
- 备注：其 24h 告警 **7 次**，若按 4.2 单独看已明显触发；但 4.3 规定返修中设备不纳入本次判定，故本行判「不适用」而非「需检修」。该设备返修完成后应优先复核。
- **判定：不适用。**

## 易错点提示（供报修核对）

1. **SV-301、SV-306 的限值不能直接取表中数值**——两行额定温度上限为空，必须回落到机柜级限值；且两者机柜用途不同，限值分别为 62℃ 与 80℃，不可混用。
2. **SV-304 温度达标但告警达标**，需检修的依据是 4.2 而非 4.1。
3. **SV-307 温度等于限值**，按「超过」的字面口径不构成 4.1 触发。
4. **SV-309 告警 7 次但不判检修**，因 4.3 的状态条款优先于 4.2；不要仅凭告警次数改判。
