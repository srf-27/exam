# 机房设备检修判定说明

- 判定依据：《机房设备维护规范 v3.2》第 4 节「停机检修判据」
- 数据来源：`巡检数据.csv`（本次巡检）
- 判定结果：见 `检修判定表.csv`
- 判定日期：2026-09-29

## 判据摘要

| 条款 | 内容 | 处理 |
| --- | --- | --- |
| 4.1 | 运行温度超过额定温度上限 | 需检修 |
| 4.2 | 24 小时内告警 ≥3 次 | 需检修（不看温度） |
| 4.3 | 状态为「厂商保修返修中」 | 不纳入本次判定，判「不适用」 |

补充规则（规范 4.1）：额定温度上限列为空的设备，按其机柜级限值执行。
机柜级限值：通用计算 62 ℃；高密度 GPU 80 ℃。

**条款优先级**：4.3 为排除性条款，先看状态；状态为「厂商保修返修中」的一律判「不适用」，
不再套用 4.1 / 4.2。其余设备再看是否触发 4.1 或 4.2，任一触发即「需检修」；
两条都不触发才是「无需检修」。

- 告警 0 次，未触发 4.2，但 4.1 已成立。

- 但 24h 告警 **3 次 ≥ 3 次**，触发 4.2（规范明确「无论温度是否超限」）。

### SV-305 —— 不适用（触发 4.3）
